# EIEM Importing Endfield MMD

[English](README_EN.md) | [中文](README.md) | 日本語

『アークナイツ：エンドフィールド』で MMD アニメーションを再生するためのプラグインです。VMD モーションの直接再生（およびベイク済みのマッスルモーション）、表情、指のアニメーション、カメラモーション、BGM の同期再生に対応し、ゲーム内の GUI パネルから操作できます。

## 機能

### 実装済み

- **VMD 直接再生モード**：標準 VMD モーションを直接読み込み、PMX や MUS4 への事前変換は不要
- **全身ボーンのリターゲティング**：ルート、上半身・下半身、頭・首、肩・腕、手首、指、脚のモーションに対応
- **脚の FK/IK**：VMD の IK 切り替えに従い、脚ごとに FK と FinalIK による IK 計算を切り替え
- **表情と目**：VMD モーフ、まばたき、口の形などの基本表情と目の動きを再生
- **カメラモーション**：VMD カメラキーフレームに対応
- **音声同期**：WAV/MP3 に対応し、再生、一時停止、シーク、ループ、終了を同期
- **地形・段差追従**：任意で有効にできる地形ポスト処理により、平地、斜面、階段への接地を自動調整
- **MUS4 マッスルモード**：95 個のマッスル値で全身のモーションを駆動
- **衣装強化**：ゲーム標準のクロスシステムを利用し、内蔵の衣装別専用設定と実行時の自動適応を組み合わせて処理

- ...

## ダウンロード

[Releases](https://github.com/Sasye/EIEM/releases) から最新リリースをダウンロードするか、ソースコードからビルドできます。

> [Applepie Manager](https://github.com/Sasye/ApplepieManager) を使用すると、本プラグインを簡単に管理・設定できます。

## インストール

以下のファイルをゲームのディレクトリ（`Endfield.exe` があるフォルダー）にコピーしてください。

```
bin/eiem.dll             → ゲームディレクトリ/plugin/eiem.dll
bin/vulkan-1.dll         → ゲームディレクトリ/vulkan-1.dll
bin/d3dcompiler_47.dll   → ゲームディレクトリ/d3dcompiler_47.dll
```

> **注意**：`d3dcompiler_47.dll`（DX 環境）と `vulkan-1.dll`（Vulkan 環境）はプロキシローダーです。どちらか一方、または両方を配置できます。同じプロキシローダーを使用する別のプラグイン（[AntiKick](https://github.com/Sasye/EndFieldAntiKick)、[SynchroFocus](https://github.com/Sasye/EndfieldSynchroFocus)、[EndfieldCombatHUD](https://github.com/Sasye/EndfieldCombatHUD) など）をすでに使用している場合、ローダーを重複して配置する必要はありません。

> **この種類のプラグインを初めてインストールする場合**は、`plugin` フォルダーを自分で作成する必要がある場合があります。

## 再生モード

| モード | モーションの入力 | 変換の要否 | 説明 |
|------|----------------|------------|------|
| **VMD 直接モード（既定）** | モーション VMD | 不要 | 全身ボーン、IK、モーフ、カメラを直接駆動 |
| **ベイク済み MUS4 マッスルモード** | MUS4 マッスルデータ | 事前のエクスポートが必要 | ベイク済み Humanoid マッスルデータを再生するパイプライン |

## リソースファイルの準備

以下のファイルを指定してください。

### VMD 直接モード（既定）

| ファイル | 説明 | 必須／任意 |
|------|------|------------|
| `*.vmd` モーション VMD | ボーンと IK に加え、既定ではモーフとカメラのデータも使用。選択すると自動的に読み込まれます | **必須** |
| `camera.vmd` カメラ VMD | 任意のカメラ VMD。未指定の場合はモーション VMD の Camera セクションを使用 | 任意 |
| `*.vmd` 表情 VMD | 任意の表情 VMD。未指定の場合はモーション VMD の Morph セクションを使用 | 任意 |
| `bgm.wav` または `bgm.mp3` | BGM | 任意 |

### ベイク済み MUS4 マッスルモード

| ファイル | 説明 | 必須／任意 |
|------|------|------------|
| `muscle_anim.bin` | MUS4 形式のモーションデータ（ExportMuscleAnimation.cs でエクスポート） | **必須** |
| `*.vmd` | VMD ファイル（表情モーフデータ） | 任意 |
| `camera.vmd` | カメラモーションデータ | 任意 |
| `bgm.wav` または `bgm.mp3` | BGM | 任意 |

## 使い方

1. 上記の手順でインストールした後、ゲームを起動してゲーム内に入ります。
2. **Insert** キーを押して GUI パネルを開きます。
3. 「ファイル」タブの上部で再生モードを選択します。既定は **VMD 直接モード**です。
4. 必要なファイルを読み込み、「コントロール」タブの **再生** ボタンをクリックするとアニメーションが始まります。

## 任意：ベイク済み MUS4 マッスルモード用のモーション書き出し（VMD → MUS4）

> **注意**：この手順は、ベイク済み MUS4 マッスルモードを使用する場合にのみ必要です。

Unity エディターで VMD アニメーションを MUS4 形式の `muscle_anim.bin` に変換する必要があります。

### 必要なもの

- Unity エディター
- [MMD4Mecanim](https://stereoarts.jp/#:~:text=MMD4Mecanim_Beta_20200105.zip) — VMD を Unity の AnimationClip に変換するためのツール
- 任意の Humanoid MMD モデル

### 手順

1. `ExportMuscleAnimation.cs` を Unity プロジェクトの `Assets/Editor/` フォルダーに配置します
2. MMD モデルをインポートして Humanoid Rig に設定し、MMD4Mecanim で VMD を AnimationClip に変換します
3. Animator Controller を作成し、変換した AnimationClip を既定のステートとして追加します
4. シーン内のモデルに Animator Controller を割り当てます
5. **モデルを選択**し、メニューバーの `Tools > Export Muscle Animation` をクリックします
6. `Assets/muscle_anim.bin` が出力されるので、ゲームの `plugin/` ディレクトリにコピーしてください
