Better Endfield Next **4.1.1** 与 BEM Tools **1.6.3**，带来昼雪免校验骨骼兼容修复、安卓界面重构与英文本地化、安卓端管理员外观对齐、持续冲刺支持「祀」、材质包加载提速、BEM Tools 22 个证据门控修复子命令与 DeepSeek Harness 创作者插件。

## Windows 4.1.1 & Android 4.1.1

- **修复昼雪旧模型包在 4.1.0 或免校验模式下的左手骨骼错位问题**：
  - 修复开启「关闭模型校验」（skip_validation）或普通名称匹配时条件短路导致昼雪专属 1.6.3 兼容与骨骼重排被跳过的问题；
  - 强制识别昼雪旧包并无条件执行 1.6.3 规范化与 10 槽位骨骼重排，彻底解决人物自身左手大拇指、食指严重扭曲与中指变形问题；
  - 补全测试套件中免校验场景下的昼雪回归断言，恢复自动化防护网。

- **安卓界面重构：主页改为「启用功能一览」**：
  - 主页只列出已开启的功能并显示实时状态（替换角色与动作、主题色、自定义配音角色数、已开启的界面与相机项、冲刺角色、悬浮窗透明度、当前 MMD 作品），点击直达对应设置页；
  - 未启用的功能不再出现在主页，入口集中在「增强功能」页；第三方模型单独保留一个主页入口；
  - 顶部导航收敛为「主页 / 增强功能 / 关于」，开屏模型、第三方模型、角色配音作为二级页面收进增强功能，二级页提供返回入口，系统返回键先回主页。
- **安卓端接入「管理员外观」模块**（与桌面端能力对齐）：
  - 宏愿武器、管理员服装、战斗与剑光特效三块各自独立开关；武器样式可选「宏愿 · 剧情水墨流光 / 原版默认外观」，角色形态可选「剧情水墨专属服装 / 剧情摘面具形态 / 原版默认形态」；
  - 配置键位与桌面端完全一致，原生模块按桌面源码原样进 NDK 构建；主页功能一览按细粒度开关动态汇总。
- **持续冲刺新增「祀」支持（双端对齐，默认关闭）**：
  - 基于 Issue #32（zhuran24）逆向研究成果精简实现。采用原生 Animator 状态回绕与坐骑墨兽同帧 CrossFade 协同驱动，伴随墨兽自适应回绕；首次回绕后自动冻结墨兽消散时钟并抑制收尾水花，全程奔跑不溶解、不脱节；
  - 纯轻量化逻辑，无需额外打包骨骼或附属件数据文件，双端设置页均提供开关，默认保持关闭。
- **安卓界面英文本地化**：
  - 系统语言为英文时，主页、增强功能、开屏模型、第三方模型、角色配音、MMD 作品库、会客室媒体屏、关于页以及游戏内悬浮窗全部切换为英文；中文环境行为与文案完全不变；
  - 角色名沿用桌面端官方英文名（如洁尔佩塔 Gilberta、梨诺 Reno、祀 Si），角色配音列表与开屏模型的角色名同步英文化；
  - 依赖中文字面量判断的操作状态栏显隐改为结构化标志，避免本地化后错误状态无法提示。
- **赞助面板新增 Ko-fi**：
  - 桌面端与安卓端赞助面板新增 Ko-fi（https://ko-fi.com/hydra405），与微信赞赏、爱发电、PayPal 并列。
- **材质包加载提速**：
  - 修复不带动画驱动的纯材质包加载时明显卡顿的问题。原因是加载过程中每处理一个材质、每构建一张贴图都要写一条日志，而日志器每次都重新打开一次文件；在开启实时防护的 Windows 上，单条日志耗时可达 10 ms 量级，上百个材质的包会白等数秒；
  - 日志器改为常驻文件句柄，逐材质、逐贴图的明细日志改为按组件、按上传事务汇总。实测单条日志成本降至原来的约 1/500，材质包加载不再被日志拖慢；
  - 诊断信息没有减少：贴图格式与尺寸、材质覆盖条数与属性总数、本次加载的贴图格式分布都保留在汇总行里。

## BEM Tools 1.6.3

- **修复工具重写**：`bem_repair.py` 重写为 22 个证据门控子命令，覆盖索引越界、超大贴图、INI 重复段、条件贴图、蒙皮调色板、合并骨架、入口程序、贴图覆盖、角色资料缺口、形变校验、选项空间、CrossIB 分组等常见源包缺陷。每个命令要么给出带数字的判定，要么以明确错误码拒绝，不会悄悄产出一份错包；所有写入都要求显式输出路径，输入文件永不修改。
- **形态键可直接转成滑条**：新增 `shape-params`，从源 INI 的 ShapeKey 缓冲生成 BEM 1.3 参数通道，用中性帧与满权重帧覆盖整个权重范围，源常量作为滑条初始值。
- **随包附带材质属性名字典**：`catalog/material-attributes.json` 收录 9 个 shader 的 1195 个 float、191 个 color、37 个 keyword 与 82 个 texture 属性名，由 747 个材质实测归并，供生成材质覆盖时查名。
- 继续只提供 BEM 1.0–1.5 的转换与校验；BEM 1.5 的 draw 级材质覆盖不提供内置自动化。

## DeepSeek Harness 插件 (dsh-bem-creator 1.6.3)

- **创作者 skill 插件化**：把创作者 skill 打包为 npm 插件包，支持 dsh plugin --profile web add dsh-bem-creator-1.6.3.tgz 直接安装至任意 DeepSeek Harness profile。
