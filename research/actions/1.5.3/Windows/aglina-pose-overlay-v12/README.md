# v12 骨骼姿态覆盖原型 / Actions 1.11.0

2026-09-10，用户授权尝试 EIEM 研究提出的运行时姿态路线。已升级测试目录与 stage 的 Actions DLL，并加入 `modules/actions/aglina_pose_v12.bin`。沿用当前 `external_loop=true` 的实验开关；此开关在 v12 选择骨骼姿态文件，不再调用外部 Clip/AssetBundle 加载。没有回滚 DLL、删除旧候选包、重新导入 Unity 动画或修改本机配置。旧模块备份路径见 `backup-path.txt`。

## 本版行为

- 保留原生 Animator、当前 Controller、移动、输入中断、道具/粒子及事件生命周期。继续使用已有 v9 的原生状态保持与时间回绕。
- 在 `CharacterAnimationComponent.TailLateTick` 原函数执行后，只处理当前已捕获角色的骨骼姿态；不覆盖角色世界根位置，不写缩放，不关闭 Animator 或全局 IK。
- 原动画进到约 `40/208` 时接入外部过程段。独立时钟以 60 Hz 的 104 个采样点（含闭合端点）播放，周期 `103/60` 秒，相位为 18 帧。原生状态的回绕不会重置此时钟。
- 进入及退出最多约 0.12 秒平滑调整覆盖权重。检测到普通攻击/停止/状态退出后，原生逻辑立即执行，视觉覆盖退回当前原生姿态。
- 每帧读取骨骼本地位置和旋转，与当前目标混合。对于原生动画未重新写入的常量通道，识别上次由本模块写入的值并去除自身残留，避免反复混合产生漂移。释放时只清理仍与本模块上次输出一致的通道，保留原生新写入的值。
- 骨骼必须属于当前 Animator 根层级；模型/根变化时放弃旧缓存。组件释放前清理，模块关闭线程只释放 GC 持有，不调用 Unity。代次检查避免托管调用重入后继续使用已释放缓存。

## 输入与已知边界

输入直接取用户认可的 `aglina-loop-test-v1/{left,right}-baked.f32` 骨骼帧，**不经过 95/101 muscle 索引转换**。文件包含 399 个具名骨骼（排除空路径的角色根），两侧各 104 帧，每骨骼仅四元数和本地位置，约 2.37 MB。要求核心骨骼全部匹配、整体至少匹配 80%；缺少可选骨骼会记录，绑定不满足要求就保留原生保持，不退回旧 Bundle 试验。

这是“直接播放已认可骨骼帧”的机制原型，**不声称已修复最初原生动画导出阶段的 95↔101 映射，也不声称现有粗修帧忠实重现原生动画通道语义**。该素材问题与新的运行时播放机制分开记录；此前 EIEM 研究结论仍然有效。

`TailLateTick` 是本版选定的写入阶段。尚未实机确认它之后是否还有其他 IK/布料/跟随组件覆盖部分骨骼；没有据此声称已完全控制最终渲染姿态。逐骨骼运行时调用的真实开销会通过 mean_apply_us 记录，本地测试不能代替游戏内帧率观察。

## 如何观察

完整重启启动器与游戏，用现有艾洁莉娜持续特殊冲刺开关试播。交付时读取到本机总动作开关 `enabled=false`、实验选项 `external_loop=true`，本轮未改设置；试播时在启动器打开原有持续特殊冲刺开关即可。

宿主日志应依次出现：

1. `Aglina v12: bone-pose file loaded`
2. `Aglina v12: bone overlay bound: matched=...`
3. `Aglina v12: TailLate pose applied side=... bones=... weight=...`

第三项才表示新的路径实际执行了骨骼写入；只出现绑定并不等于已经显示。正常退出会出现 `pose overlay released`。同时出现 `v9 normalized bob blend` 是预期的原生状态保持日志，不再表示视觉姿态一定来自旧循环。

若希望只用原生 v9 保持，可设动作节 `external_loop=false`；该开关已有启动器保存保留支持。关闭 UI 总动作开关也会结束保持并交还姿态。

实现入口：`native/modules/actions/pose_policy.h`、`pose_overlay.inl`、`pose_overlay_tests.cpp`；输入生成脚本：`tmp_analysis/prepare_aglina_pose_overlay.py`。本轮没有启动游戏，实际显示与衔接效果待本次试播。
