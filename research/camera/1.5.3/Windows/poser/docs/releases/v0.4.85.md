# Endfield Poser 0.4.85

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.85)

## 本次更新

- **播放倒计时**：单人、多人均可选 1–10 秒，默认关闭。人物与镜头先进入初始帧，数字消失时动作和音乐开始；隐藏菜单仍能看到倒计时。
- **多人衣物增强**：各队员独立处理，默认开启；改进启动准备与停止恢复，减轻集中准备时的卡顿。
- **切人后播放**：角色或编队加载期间的播放请求会等待新模型与衣物就绪；再次换人或停止会取消原请求。
- **管理员外套**：减少连续固定点，增加胸腰碰撞体；男管理员补充小腿及骨盆过渡碰撞体，改善腰与腿根的覆盖。保留原有蒙皮。
- **动作适配**：准标准骨补全默认全开；已有预设保留原选择。
- **界面整理**：移除反复跳动的编辑占用提示和试用版物理可视化。
- **XXMI 联动拆分**：默认构建和 Release 安装包不包含联动，需要时单独构建。通过 EFMI 启动游戏仍可使用标准版。

已通过 44 组自动化测试、构建和管理员碰撞几何检查。新版物理仍待完整实机验收，不能保证消除穿模；切队后衣物恢复等待也仍需继续验证，本次按预发布提供。

## 安装与更新

在 **Assets** 下载 `Endfield-Poser-v0.4.85-win64.zip`。`source.zip` 和 **Source code** 为源码，不能直接安装。

1. 完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击**新版包内的安全安装.bat**，选择直接包含 `Endfield.exe` 的目录，再选 **安装或更新**。
3. 启动游戏，确认使用协议。按 **L** 打开面板，需要光标时按住 **Alt**。

无需先卸载；向导自动备份，保留配置、姿态和自定义校准，并安装 37 份内置表情校准。更新向导使用包内文件，不会自动下载新版。衣物资源已内嵌 DLL，无需额外寻找 `assets/cloth`。

## 使用提示

**倒计时**：播放前勾选 **播放倒计时** 并设置秒数；单人、多人共用此设置。暂停会暂停倒计时，停止、重置或拖动进度会取消它。

**衣物增强**：单人在 **动作 → 衣物物理** 开启 **服装碰撞增强**；多人在 **站位与适配** 调整 **全队衣物物理增强**。保持 **冻结头发／衣物** 关闭。若准备失败或恢复等待不结束，可停止并关闭增强后重试。

**快捷键**：L 显示／隐藏面板，P 冻结／解冻；**Ctrl+F5 播放、Ctrl+F6 暂停、Ctrl+F7 停止、Ctrl+F8 重置动作**。已有自定义按键保留。
