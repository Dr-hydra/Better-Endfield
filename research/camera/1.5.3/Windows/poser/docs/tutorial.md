# 快速教程

先按[安装说明](../README.md#安装更新与卸载)完成安装，再进入可操作角色的场景。

## 打开与整理面板

按 **L** 显示或隐藏面板；需要鼠标光标时按住 **Alt**。拖动标题栏可以移动窗口，拖不动时取消 **锁定窗口**。点击 **重排窗口** 可恢复初始布局。

播放器顶部保留播放、暂停、停止、进度、速度和循环，下方按用途分组：

| 入口 | 内容 |
|---|---|
| 单人 → 动作 | IK、位移比例、高度、地形、动作幅度、衣物物理 |
| 单人 → 镜头与音乐 | 选择文件、同步播放、镜头构图 |
| 单人 → 表情 | 播放时的映射来源、整体和分区强度 |
| 单人 → 高级 | PMX、A/T 姿、备用校准、追加骨骼、诊断报告 |
| 多人播放器 | 分为队员与动作、站位与适配、镜头与音乐 |
| 独立表情面板 | 手动表情滑条、眼睛方向、MMD 眼神锁定 |

自动位移适配开启时隐藏手动比例；眼神锁定在独立表情面板统一控制。长文件路径可悬停文件名查看。

## 手工摆姿并保存

1. 按 **P** 冻结当前角色。
2. 在画面或骨骼面板中选中骨骼，用旋转工具或参数调整姿势。
3. 如需固定并编辑头发、裙子等部位，勾选 **冻结飘带／裙子／头发**；该选项默认关闭。
4. 在 **姿态库** 输入名称并保存，之后选中姿态即可载入。
5. 按 **P** 解冻，恢复游戏动作。

姿态库默认不保存或套用面部表情。载入其他角色的姿态后，可能需要微调手脚。

## 眼睛朝向

在 **表情 → 眼睛朝向** 中选择 **手动方向** 或 **锁定当前摄像机**，冻结角色或播放动作后生效。手动模式用左右、上下滑条调整方向，**方向归零** 恢复正前方。左右以角色自身为准。

播放 MMD 时可直接勾选 **MMD 播放时锁定摄像机**，用 **锁定强度** 混合原动作眼神和看向镜头的效果。单人、多人共用此开关，关闭后恢复当前动作眼神。

展开 **校正与限位（当前角色）**，可微调看向镜头的偏差，并分别设置向左、向右、向上、向下的最大角度。修改自动按角色保存，单人和多人共用；**恢复角色默认** 清除个人调整。斜向转动和动作眼神混合后也会限位，强度为 0 时保留原动作。

匹配到角色 PMX 参考时，自动采用虹膜基准和可用的眼眶估算限位；无法可靠估算时显示通用限位。它们基于中性脸，眯眼或替换皮肤后仍可能需要收紧。新版基准下先用默认校正，再观察是否还需要此前的上下偏移。

播放、暂停及隐藏面板时仍生效，支持游戏镜头与 MMD 镜头。切回 **跟随游戏 / 动作** 恢复原有眼神；换角色或刷新骨架会退出接管，但保留各角色校正。只改变眼球方向，眉毛、眨眼和口型仍按原设置播放；镜头在身后时回到正前方。

若角色缺少虹膜参考点，面板会提示使用手动方向；未读取到镜头时会暂时恢复原眼神。
自动看向镜头会保留角色原本的双眼布局；镜头靠近时限制双眼汇聚幅度，避免过度对眼。

## 手动调节 MMD 表情

在 **表情** 面板顶部选择 **MMD 模式**，按 **P** 冻结角色，即可按 **眉毛、眼睛、嘴部、其他** 调节中文表情滑条，无需载入 VMD。多个表情可以叠加；支持单项、本组、全部归零和整体强度调整。悬停标签可查看原始 MMD 名称。

优先使用当前角色的专属映射，可勾选 **缺失时使用固定映射**；当前无可用映射的滑条会隐藏并显示数量。切回 **游戏模式** 恢复切换前的游戏滑条设置；隐藏面板保持表情。播放或暂停动作时手动滑条暂不可用，停止后恢复此前手动设置。换角色或刷新骨架会清空手动 MMD 表情。

## 播放一个 MMD 动作

1. 勾选 **MMD 播放器**，点击 **打开 VMD**。
2. 播放时自动适配骨架和腿长，失败时才需要 **高级 → 角色校准 → 备用手动 T 姿**。
3. 点击 **播放**。需要配乐或镜头时，在 **镜头与音乐** 页选择对应文件。
4. 用进度条查看动作，暂停后可在姿态库保存当前身体姿态。
5. 按 **L** 隐藏面板，用快捷键继续控制播放。

更换角色会结束当前播放，已打开的动作保留。播放或暂停期间，手工骨骼编辑、姿态载入和普通表情滑条暂不可用；需要编辑时先 **停止并恢复**。

## 默认快捷键

| 按键 | 操作 |
|---|---|
| `L` | 显示／隐藏面板 |
| `P` | 冻结／解冻；播放中先退出播放器 |
| 按住 `Alt` | 呼出光标操作面板 |
| `Ctrl+F5` | 播放／继续 |
| `Ctrl+F6` | 暂停并保持姿态 |
| `Ctrl+F7` | 停止并恢复播放前状态 |
| `Ctrl+F8` | 回到首帧并暂停 |

在主面板 **快捷键设置** 中查看并重新绑定。已有设置优先，以面板显示为准；避免使用与其他插件冲突的按键。
