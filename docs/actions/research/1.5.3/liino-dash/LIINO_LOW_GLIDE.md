# 梨诺低位平滑滑翔修复（2026-09-14）

旧姿态数据采用源帧 52–104，交叠 ±14。接缝虽然闭合，但循环内部保留了从低位滑翔到明显上升的运动，实际循环骨盆高度峰谷差约 44.3 cm。该问题由动画内容造成，不是 Animator 回绕接缝或世界坐标漂移。

## 采用的区间

选源帧 **46–66**，在接缝两侧各取 8 帧真实源数据作五次平滑交叠，实际读取源帧 38–74。随后将闭合段放慢到 **0.5 倍速度**，以位置插值和旋转 slerp 重新采样到 60 Hz，得到 **40 帧周期 / 41 个采样 / 0.6667 秒**。没有额外抬高角色、锁定骨盆高度或写入世界根节点。

源帧均为 60 Hz、从零开始计数。切入点为源帧 **56**（`56/173 = 0.323699`），数据内相位 **20**。该帧位于未受接缝混合影响的内部区间，与原生源姿态一致；后续由已有的 0.12 秒淡入接管，并按半速播放。

高位候选用相同宽度的源帧 86–106、交叠 ±8 比较。它仍跨越抬身准备落地的运动，骨盆和脚部起伏都明显大于低位段，因此没有采用。

| 左动画模型空间高度峰谷差 | 旧 52–104 | 低位 46–66（采用） | 高位 86–106 |
| --- | ---: | ---: | ---: |
| 骨盆 `Bip001` | 44.31 cm | 3.87 cm | 11.63 cm |
| 头部 | 48.46 cm | 5.22 cm | 15.67 cm |
| 左脚踝 | 48.74 cm | 5.99 cm | 14.96 cm |
| 右脚踝 | 25.55 cm | 3.23 cm | 16.66 cm |

右动画的双脚指标互换，骨盆起伏 3.87 cm。这里测量的是骨骼模型空间高度，不是滑板网格的最低点，也不等同于游戏地形上的实际离地距离。低位依然保留小幅自然运动。

## 复现

在冲刺动画工作树运行（参数换成本机绝对路径）：

```powershell
python tools/actions/build_liino_glide.py --source '<主工作区>/tmp_analysis/liino-fbx-validation' --output '<主工作区>/tmp_analysis/liino-glide-v2/final'
```

脚本仅依赖 NumPy，输入为已经过 Unity Avatar 验证的 174 帧左右骨骼烘焙，不需要重新解包或启动 Unity。输出包括 `pose_liino.bin`、元数据、完整骨骼 `.f32` 和 FBX 导出所需的已有烘焙描述。脚本检查原始骨架、旋转归一化、切入姿态、闭合端点，以及骨盆、头部、双脚高度阈值。

骨骼筛选与旧数据保持一致：339 根，22 根 Humanoid 必需；排除静止、面部和视线骨骼，不写缩放。格式仍是 `BEPOSE12` v1，文件 **826,638 字节**。无需改 DLL。Animator 的 107/173 → 55/173 回绕只是维持原生状态，继续使用原参数；骨骼覆盖拥有独立时钟，二者不锁相。关闭 `external_loop` 会回到原生姿态保持路径，此修复也随之关闭。
