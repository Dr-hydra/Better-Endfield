# Blender 摆姿桥接

在 Blender 中调整角色骨骼姿态，再同步回游戏。仅用于摆姿，不导入角色外观；游戏内 MMD 播放无需安装此插件。插件要求 Blender 5.2 或以上版本。

## 安装与连接

1. 按[安装说明](../../../README.md#安装更新与卸载)启用游戏内插件，确认使用协议并进入角色场景。
2. 将 `endfield_poser_bridge` 文件夹压缩为 ZIP，在 Blender 的插件管理中从磁盘安装并启用 **Endfield Poser Bridge**。
3. 在 Blender 的 3D 视图按 **N**，打开 **Endfield** 页签。
4. 先在游戏内按 **P** 冻结角色，再点击 **连接游戏并创建骨架**。

## 摆姿与同步

| 操作 | 用途 |
|---|---|
| 导入姿势（游戏→Blender） | 将游戏当前姿势带入 Blender |
| 导出姿势（Blender→游戏） | 将 Blender 中调整后的姿势同步回游戏 |
| 自动同步（Blender→游戏） | 持续预览 Blender 中的调整 |

连接后进入 Blender 的 **Pose 模式**，先小幅调整手臂等部位，确认方向正确，再继续摆姿。同步完成后可在游戏的姿态库中保存。

## 注意事项

- MMD 播放或暂停时，先在游戏中点击 **停止并恢复**，再使用桥接编辑。
- 换角色后先关闭自动同步，重新连接并检查骨架，再继续操作。
- 同步会影响手指、配饰等多个部位，建议先保存原姿态。游戏内锁定的骨骼不会被覆盖。
- 部分骨骼方向可能与 Blender 预览不同，请以游戏画面为准。
- 连接失败时检查游戏内插件是否启用；可用浏览器访问本机 `http://127.0.0.1:18923` 确认连接。
