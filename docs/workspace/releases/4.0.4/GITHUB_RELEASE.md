Better Endfield Next **4.0.4（Windows）** 与 BEM Tools **1.5.4**，更新 Steam 国服配置、昼雪旧模型包兼容和角色创作资料。

## Windows 4.0.4

- **Steam 启动选项自动配置**：应用配置时自动填写当前账号，更换加载方式或路径后可在 Steam 完整退出时更新。修复直接运行占位 EXE 导致的“平台无效”，移除配置时恢复原启动选项。
- 正常保留 AppID 正确的 `steam_appid.txt`；其他文件冲突提供显示路径和删除范围的确认操作。自动更新不会强制清理目录。
- 隐藏 BE / Steam 启动辅助程序的常驻控制台，保留错误提示。
- **恢复昼雪旧 BEM 的兼容**：针对游戏 Windows 1.6.3 的原网格和骨骼顺序变化进行定点适配，旧包无需重新打包，不关闭其他资源的校验。代表旧包已完成 12 部件开屏替换，并获用户实机确认。
- 修复持续冲刺模块因可选诊断接口缺失而无法加载的问题；接口缺失不再影响必要的动画状态读取。

## BEM Tools 1.5.4

- 更新昼雪当前世界/详情资料，保留原 12 个组件编号，包含 11 个索引身份、41 个纹理身份及真实运行时声明。
- 新增世界/详情共 24 部件的可编辑 keep-only 工程，保留祀和明河资料。
- 提供完整工具 ZIP 和单独角色资料补丁；完整工具无需另外安装 Python 或 .NET。

昼雪有 8/12 个部件符合现有来源自动转换布局。其余布局和多子网格限制继续保留；keep-only 工程是创作起点，单独打包不会改变模型。原始 UI 资料已经采集，旧包详情页显示及所有昼雪包尚未逐一实测。
