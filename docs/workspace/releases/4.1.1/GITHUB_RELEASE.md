Better Endfield Next **4.1.1** 开发记录。

## Windows 4.1.1 & Android 4.1.1

- **安卓界面重构：主页改为「启用功能一览」**：
  - 主页只列出已开启的功能并显示实时状态（替换角色与动作、主题色、自定义配音角色数、已开启的界面与相机项、冲刺角色、悬浮窗透明度、当前 MMD 作品），点击直达对应设置页；
  - 未启用的功能不再出现在主页，入口集中在「增强功能」页；第三方模型单独保留一个主页入口；
  - 顶部导航收敛为「主页 / 增强功能 / 关于」，开屏模型、第三方模型、角色配音作为二级页面收进增强功能，二级页提供返回入口，系统返回键先回主页。
- **安卓端接入「管理员外观」模块**（与桌面端能力对齐）：
  - 宏愿武器、管理员服装、战斗与剑光特效三块各自独立开关；武器样式可选「宏愿 · 剧情水墨流光 / 原版默认外观」，角色形态可选「剧情水墨专属服装 / 剧情摘面具形态 / 原版默认形态」；
  - 配置键位与桌面端完全一致，原生模块按桌面源码原样进 NDK 构建；主页功能一览按细粒度开关动态汇总。
- **持续冲刺新增「祀」支持（双端对齐，默认关闭）**：
  - 基于 Issue #32（zhuran24）逆向研究成果精简实现。采用原生 Animator 状态回绕与坐骑墨兽同帧 CrossFade 协同驱动，伴随墨兽自适应回绕；首次回绕后自动冻结墨兽消散时钟并抑制收尾水花，全程奔跑不溶解、不脱节；
  - 纯轻量化逻辑，无需额外打包骨骼或附属件数据文件，双端设置页均提供开关，默认保持关闭。
