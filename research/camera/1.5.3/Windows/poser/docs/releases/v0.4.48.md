# Endfield Poser 0.4.48

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.48)

## 主要变化

- 使用角色专属表情校准替代通用模板；内置 37 份校准，缺失时可选择固定表情映射，支持分部位强度。
- 表情面板新增 **MMD 模式**，使用中文标签调节眉毛、眼睛、嘴部等表情，支持叠加和归零。
- 校准随安装包自动安装；更新保留用户修改过的校准、配置和姿态。
- 修正部分表情名称漏配，改善冻结时自动眨眼干扰，并修复动作播放等待与退出收尾问题。
- 衣物恢复使用游戏原有物理，移除额外的防穿地、补建碰撞体等修正。

## 安装与使用

在 **Assets** 中下载 `Endfield-Poser-v0.4.48-win64.zip`，源码包不含可直接使用的 DLL。

1. 退出游戏，完整解压安装包。
2. 双击 **安全安装.bat**，选择含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏目录，再选 **安装或更新**。
3. 按原有方式启动游戏，阅读并确认使用协议。进入角色场景后按 **L** 打开面板，按住 **Alt** 操作鼠标。
4. 手动表情：按 **P** 冻结，在 **表情 → MMD 模式** 调整滑条。播放动作时则在 **角色表情与强度** 中调整映射和强度。

安装器自动备份更新文件；自定义校准与内置文件同名且内容不同时，会提示并保留。卸载时退出游戏，运行同一向导并选择 **卸载**，用户数据与备份保留。

播放快捷键：`Ctrl+F5` 播放、`Ctrl+F6` 暂停、`Ctrl+F7` 停止恢复、`Ctrl+F8` 回到首帧。按 **L** 隐藏面板后继续播放。
