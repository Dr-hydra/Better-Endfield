# XXMI 联动（仅单独构建）

默认构建和 GitHub Release 安装包均不包含此功能，也不会显示联动面板。需要时自行构建：

```bat
build.bat -EnableXxmiBridge
```

产物位于 `build/xxmi/plugin/`，不会覆盖标准版的 `plugin/`。先安装标准版，退出游戏并备份游戏内 `plugin/poser.dll`，再用此目录中的 `poser.dll` 替换。恢复标准版时运行标准安装包的向导即可，原有联动设置保留但不再读取。

使用 CMake 时，在单独的构建目录配置 `-DPOSER_ENABLE_XXMI_BRIDGE=ON`；默认值为 `OFF`。`tools/package.ps1` 只允许打包不含联动的标准版。

## 使用

通过 EFMI 启动游戏时，可以用 VMD 自定义表情轨道切换服装、配件等 Mod 选项。目前用于单人播放，默认关闭；不会修改原 Mod 文件。

1. 在播放器 **高级 → Mod 联动（实验）** 中确认已读取 Mod 设置，勾选 **用表情轨道切换 mod 变量**。
2. 在 MMD 或 Blender 中给自定义名称的表情打关键帧，例如 `襟OFF`，随动作导出，或用 **追加口型 / 表情 / 眼神** 追加。表情名最多 15 字节，约 7 个汉字。
3. 打开动作后，在该轨道下选择 **添加 mod 变量**。同一轨道可以添加多个 mod 的变量，让一份动作适配不同角色。
4. 停止播放时按一次 **F10**，或重启游戏，让 EFMI 读取桥接文件。显示 **联动已生效** 后即可播放。

表情权重 0 对应列表中的第一个值，1 对应最后一个值，中间取最近的一档；只有两档时以 0.5 为界。**反转顺序** 可以交换对应关系。

开始播放时，EFMI 会记下这些变量当前的值，**停止并恢复** 后还原。拖动、循环和回到首帧时按当前帧重新计算。之后播放无需重载，只有新增绑定后才需要再按一次 F10。

最多约 29 个取值，实际数量受已有绑定影响。绑定保存在 `plugin/mmd/mod-bridge.json`，辅助文件位于 EFMI 的 `Mods/EndfieldPoserBridge/`；关闭联动会移除辅助文件。**播放中不要按 F10，否则停止后可能无法还原。**

面板会提示 Mod 与插件的快捷键冲突。请在主面板 **快捷键设置** 中更改组合键，或修改该 Mod 的按键。

## 排查

停止后按 F10 或重启游戏使新增绑定生效。若取值仍未生效，确认 XXMI 的 mod 按键已开启，且游戏位于前台。
