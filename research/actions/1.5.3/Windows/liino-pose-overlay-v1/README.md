# 梨诺特殊冲刺姿态数据 v1

`pose_liino.bin`：`BEPOSE12` v1 格式，运行时由 Actions 1.12.0 的 `CharacterProfile` 按角色加载（路径 `modules/actions/pose_liino.bin`）。

## 数据

- 源 Clip `A_actor_liino_sprint_dash_sp_l/r`，174 采样 / 60 Hz / 2.8833 秒，460 条 Transform 轨道，152 条 Float 通道（0–41 Motion/Root/IK 参考，42–142 为 101 条 muscle，143–151 为 9 条 IK 权重）。
- 烘焙：`tmp_analysis/liino-fbx-validation`，Unity 2022.3.62f3 + 原 Avatar，muscle 往返最大差 0.00023，Avatar 缩放 0.9917296 与源一致，592 根骨骼。
- 循环：`tmp_analysis/liino-loop-fine-v1`，源帧 52–104，接缝两侧各 14 帧用真实源数据交叠淡化，周期 52 帧 / 0.8667 秒，源帧 67–89 未改动。
- 打包：339 根骨骼（22 根 Humanoid 标记必需），剔除 154 根源片段内完全静止的骨骼和 98 根面部 / 视线骨骼，1 根无路径。相位 26，切入归一化时间 78/173 = 0.45087，文件 1,054,446 字节，sha256 `0b1a9f24…`。

相位选在交叠区之外，所以覆盖接管的那一帧正好等于源帧 78 的真实姿态，淡入不会撞上混合帧。

## 接缝质量

口径：每根非面部骨骼，循环接缝处的角加速度 ÷ 这根骨骼在原始片段里自身出现过的最大角加速度。小于 1 表示接缝突变不超过原动作自带的抖动。

| 参数 | 周期 | 最差比值 | 最差骨骼 |
| --- | --- | --- | --- |
| 52–104，±14（采用） | 0.87 秒 | 0.63 | `sleeve_base_R_c_02_jnt` |
| 40–80，±18（先前候选） | 0.67 秒 | 1.68 | `IK_Weapon_R_001` |
| 洁尔佩塔 22–125，±22（已发布） | 1.72 秒 | 0.94 | `IK_Weapon_L_001` |

身体骨骼单独看：接缝角加速度峰值 2.18 °/帧²、均值 0.51，洁尔佩塔为 0.99 / 0.47。

Blender 校验（`blender-loop-validation.json`）：FBX 与烘焙样本位置差 1.8e-6 m，端点差 0，四周期重复差 0。

## 注意

- 循环窗口的交叠读取源帧 38–118，全部在落地之前（落地语音 2.134 秒 ≈ 帧 128，随后有脚步事件），所以循环里不含落地姿态。
- 梨诺的 Perform 在 2.2 秒用 `CharMeshGroupShowActData` 收起滑板，运行时靠 `SetCharMeshGroupShow` 钩子在保持期间抑制；该钩子是可选契约。
- 她的特效 duration 多为 -1，随 Perform 存续，不需要洁尔佩塔那套粒子寿命保持。
- 周期 0.87 秒，比洁尔佩塔的 1.72 秒短，长时间保持时重复感更明显。
