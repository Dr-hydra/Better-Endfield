## 数据与规则

`tools/CustomModel/catalog/` 随创作者工具发布，只有原生名称、骨骼顺序、布局、材质槽及来源证据，不含游戏 Mesh 或纹理像素。
`entries` 将 EFMI 原生资源 hash 指向资料中的组件 ID。源包 ComponentN 数字可以变化，不能用它作为全局部位编号。
当前资料不由普通用户手选；多版本匹配不唯一、身份未知或原生索引数不符均拒绝自动转换。
源资源 hash 是 EFMI 提供的标识，不是生成的产物校验哈希。

## 通用转换行为

只识别明确的标准本地骨架分发模板；静态求值默认开关，再读取真正选中的资源声明和绘制段。
支持包内任意资源文件名、UINT16/UINT32 几何索引，顶点流与目录声明一致时直接保留。
隐藏部分绘制时重建只含选中三角形的索引缓冲。空回调表示隐藏，不能错误保留原模型。
原生单 submesh 多材质依次重放；每段绑定指定原生材质及对应纹理。
未知贴图、条件、非零 base vertex、缓冲动态切换、合并骨架、外部材质框架均不会被当作标准情况静默通过。

`inspect` 执行完整转换准备和几何校验，通过才返回 `conversion_ready=true`；`convert` 重新核对输入后写入 BEM。
UI 对 ready 显示“转换为 BEM”，无需配方。其余来源显示具体缺项并允许保存报告。
