## 正式实现

- 旧入口保存为 `module_legacy.cpp`，其内容除 legacy 说明外与 `84b88bfb` 一致，原 `.inc` 文件保留。正式 DLL 只编译新的 `module.cpp` 和拆出的 BEM、注册表、原生字段解析代码。
- 唯一模型替换入口为 `BundleLoader.AssetProxy._FinishWithAsset` 前。先准备整份模型的 Mesh、私有材质和纹理，再提交并读回；失败恢复原绑定，原回调恰好执行一次。
- Mesh 使用当前源资源的声明、stride、bindposes 和原名称，保留 packed skin 和 `UploadMeshData(false)`。`m_BonesPerVertex` 的偏移由两个一致的原生序列化函数解析；构造后、上传前复制匹配源 Mesh 的值，上传后检查一致性。`m_CachedPtr` 从元数据解析，没有固定偏移回退。
- 构造阶段使用临时 GCHandle，原交付回调前解除；提交后仅保留弱引用，使用游戏的正常资源引用关系。CPU payload 按角色需求读取，128 MiB 上限、10 秒闲置到期。懒加载通过不等于已证明所有 GPU 资源释放边界。
- LOD 有效状态为“启用 Mod 或独立 LOD 开关开启”。正式采用已验证的 B5：保护 HG parent/art tag bias 不被后续设置覆盖，持续维护质量与五项 NPC 参数；关闭时解除保护并恢复。字段和方法均从元数据解析。
- Host 提供命名能力 `BetterEndfield_RetireModuleHooksV1`，安全停用入口并保留仍可能被在途回调使用的跳板；不改变 Host API V1 结构。
