# 梨诺无机甲冲刺（1.13.3）

启用梨诺持续冲刺后，「隐藏机甲与光效」独立开关控制机甲、腿甲及冲刺光效，沿用此前低位半速的闭合飞行动画。开关支持中英文，默认开启，与已确认效果的 1.13.2-clean 测试版一致；关闭时恢复保留外观的行为。配置键 `liino_clean` 在模块和 UI 中均默认 true，缺少此键的旧测试配置沿用无机甲效果。关闭梨诺持续冲刺时，外观开关变灰并保留偏好；单页保存、完整保存和重新加载均读写该键，`external_loop` 的现有取值仍保留。其他角色的动画和光效保持原有行为。

`CharPerformHandleBase.get_interactPerformId` 和 `get_entity` 从运行时元数据解析。每次拦截直接核对 `CharIntPerform_Liino_Spdash`、有效 Entity 与主控身份；不依赖在原生 StartSpDash 返回后才建立的持续动画会话，因此覆盖起步第一帧及退出阶段。配置关闭、角色未启用、其他 Perform、其他 Entity、非游戏线程或元数据异常均放行。

- 跳过该 Perform 的全部 EffectPlayAction.OnPlay，包含资源中的 22 个粒子/材质效果槽。效果不会创建，因此没有入场闪现或退场溶解，不需要强行销毁共享效果对象。
- 跳过同一实体 MeshGroup1/2 的显示和隐藏调用。枚举值仍由运行时解析；不触碰其他网格组。原生 SetCharMeshGroupShow 的首次调用把 `!show` 写入恢复缓存（本地 GameAssembly RVA 0x064972CB–0x064972DB），因此不能简单把 true 替换为 false，否则退出时可能错误恢复显示。跳过两边可保留原始网格状态及原生其他清理。
- 无机甲策略所需任一接口/钩子缺失时，整体回退到保留外观的逻辑，并记录诊断日志。未修改游戏文件、模型资源或骨骼数据。

验证覆盖无动画会话时的起步拦截、22 个槽、退出阶段、两组显隐均不调用原生缓存、外部实体/其他角色/关闭/异常/非游戏线程放行，以及此前保留外观和效果清理回归。四组原生测试通过。离线测试不证明实际渲染结果；需重启游戏检查起步、左右侧、转向、长冲刺、松键、跳跃、换人和战斗时的装备恢复。

用户已确认 1.13.2-clean 的实际效果。1.13.3 仅增加 UI 配置连接并去掉测试版本后缀，按要求进行 Release 构建、配置冒烟检查与现有显隐回归，不再次实机测试。
