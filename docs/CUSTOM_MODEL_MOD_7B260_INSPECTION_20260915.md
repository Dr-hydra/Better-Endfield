## 配置问题

1. C7 的 `drawindexedinstanced` 请求 43,524 个索引，文件只有 43,518 个，多出 6 个索引。应核实使用完整 IB 的 43,518 个是否符合作者预期，不能直接沿用较大的绘制数量。
2. `TextureOverride_Component0_LOD0` 引用 `ResourceNormalmap`，包内没有该资源节。这个名称带 `_LOD0` 的覆盖节实际将 `$lod_detected` 设置为 1；不能凭节名认定是原生 LOD0。
3. 配置调用外部 `RabbitFX/RabbitFx\SetTextures`；包内不包含该命令实现。将几何和 DDS 导入 BEM 不等于已经复现 RabbitFX 的材质效果，需检查对应原生材质槽位及渲染行为。
4. `mod.ini` 与 `DISABLED_mod.ini` 并非完全一致，观察到 RabbitFX 命令命名大小写差异；另有 4 份历史配置备份。导入应显式选用当前 `mod.ini`，不能依赖模糊后缀查找。
