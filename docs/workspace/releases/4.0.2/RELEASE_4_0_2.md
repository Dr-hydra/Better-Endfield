# Better Endfield Next 4.0.2

4.0.x 用户可覆盖更新，保留 Next 设置。Android versionCode 为 40002，安装身份与签名沿用 Next。

## 更新

- **会客室媒体屏**：新增图片、视频来源；Windows 支持把本地窗口投影到会客室大屏和桌面电脑屏，大小屏可独立开关，桌屏支持比例适配。分辨率与帧率提供预设和自定义。
- **窗口投影操控**：Windows 支持转发键鼠到选定来源，新增 Unity／UE 来源输入桥，操控时屏蔽终末地自身输入；Muse Dash 已验证并由用户确认可用。窗口投影可选择暂停游戏 BGM。
- **可自定义热键**：默认 `-` 开始／结束投影，`Ctrl+-` 暂停／继续视频，`Alt+-` 开启／退出窗口操控。操控时 Esc 转给来源。

## 下载

- `BetterEndfieldNext-4.0.2-Setup.exe`：Windows x64 安装包。
- `BetterEndfieldNext-4.0.2-Android-arm64.apk`：Android arm64。
- `BEM-Tools-1.5.2-win-x64.zip`：独立模型创作者工具。

UE 来源尚未实机验收，不保证所有游戏的输入后端兼容。Android 的媒体文件支持已通过构建与离线检查，未宣称本版完成手机画面验收；本地窗口投影和键鼠转发目前用于 Windows。
