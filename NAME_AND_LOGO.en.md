# Name and Logo Usage Notice

[简体中文](NAME_AND_LOGO.md)

Better Endfield ("the Project") uses the following name and icon as its public identity. To prevent mistaken identity, confusion about the source, or being presented as an official channel of the Project, please follow this notice.

## The Project name and icon

- **Name**: Better Endfield (also written Better Endfield Next; "Next" is a version suffix and is not emphasized); commonly abbreviated as BEM (also BE).
- **App icon**: an icon based on the game character Gilberta, see [`ui/BetterEndfieldNext.UI/Assets/shared/gilberta.ico`](ui/BetterEndfieldNext.UI/Assets/shared/gilberta.ico) and [`android/app/src/main/res/drawable-nodpi/gilberta.png`](android/app/src/main/res/drawable-nodpi/gilberta.png). Rights to that character belong to the game's rights holders; the Project uses it only as its own app icon.

## Uses to avoid

Do not use the same, or confusingly similar, names or icons in the following ways:

1. Naming your software, module, channel, account or distribution page "Better Endfield", "Better Endfield Next", "BEM", or a near-identical variant (including changes only in capitalization, spacing, punctuation, digits or individual words, or "Better Endfield" plus version, platform or "official/enhanced/Chinese"-style qualifiers).
2. Using an image the same as or similar to the Project's app icon as your own product logo, avatar, cover art or installer icon.
3. Using those names or icons in a way that implies "official", "authorized" or "affiliated with the Project", especially for charges, fundraising, bundled distribution or third-party installers.

## Uses that are fine

No prior contact is needed to:

- Mention the Project's name accurately in guides, reviews, discussions and reporting;
- Link to or reference the Project's official repository and release page, including badges;
- Credit the source and author accurately in derivative or fan works, provided the Project's name or icon are not used as your own product name or trademark.

## Note

Rights to the character in the app icon, and to names such as "Endfield", belong to their respective holders. The Project is independent and unofficial, and is not affiliated with the game developers or publishers. This notice only expresses the Project's preferences for the use of its own name and icon, with the aim of avoiding confusion; it claims no rights over game names, characters or trademarks, and grants no license or authorization.

For use in collaboration, distribution or brand partnership scenarios, please contact the Project in advance via a repository issue or the channels listed on the release page.
