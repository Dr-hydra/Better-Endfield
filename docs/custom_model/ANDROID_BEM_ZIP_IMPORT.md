# Android BEM / ZIP 导入

适用于 Better Endfield Next 4.0.0。第三方模型页的「导入 BEM / ZIP」支持单个 BEM，以及包含多个 BEM 的 ZIP。也可以从文件管理器通过打开方式或分享将 ZIP 交给应用。

ZIP 根目录和子目录中的 `.bem` 文件都会参与校验，扩展名不区分大小写；其他文件忽略。同名文件位于不同子目录时分别处理，不使用压缩包内路径创建安装目录。

校验完成后显示模型包选择列表，默认勾选所有可导入项。可以取消勾选部分包；旋转屏幕时保留尚未确认的选择。无效包列在选择列表下方，点击「导入所选」后逐包发布并保存，结果显示成功数量和失败项。

每个导入项复用原有原样导入、Android 资源目标验证、组件/外观/滑条和冲突处理。同一角色或资源目标重叠时，按既有 Android 规则仅启用最后成功导入的包；其他已安装包保留。后续项失败不会撤销已经成功导入的项。

取消选择列表不会修改已有安装索引。导入执行期间取消会停止后续项，已经完成的项保留。临时文件会清理；文件管理器中的原始 BEM / ZIP 不会修改。常规设置在重启游戏后生效，实验热切换仍沿用正常资源重载行为。

ZIP 读取上限为 8 GiB，累计解压 BEM 字节上限为 8 GiB，每个 BEM 上限为 2 GiB；最多 4,096 个 ZIP 条目和 256 个 BEM。支持存储、Deflate 和常见 UTF-8/GBK 文件名；分卷、加密或其他压缩方式需要先转换为普通 ZIP。条目长度和 CRC 会校验，非法路径及损坏包不会发布。

主机回归覆盖真实 ZIP 解包、字节保留、嵌套目录、同名文件、大小写、编码、CRC、大小/数量限制、取消，以及真实安装索引的勾选发布、部分失败和保存回滚。Android Release、R8 和 lint 属于构建验证，文件管理器路由、对话框显示及游戏内效果仍需手机验收。
