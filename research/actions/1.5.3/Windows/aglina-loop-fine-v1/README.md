# 特殊冲刺 Loop 细修版（基于修正映射的第三版烘焙）

2026-09-13。输入为 `aglina-fbx-validation-v3` 的修正重建。用户要求在路线已通的前提下从原始完整动作重做一版细修。

## 动作特征

这段特殊冲刺是滑翔：根高度在源帧 8 到峰、40 到谷、约 98 到峰、138 到谷、156 再到峰，随后 170 帧起落地。循环段内双脚离地 0.27–1.2 m，不存在脚部接触问题；需要处理的是身体姿态衔接和头发、飘带、尾饰、袖口等次级骨骼链。

## 区间

用修正数据重新做全身边界搜索（`analyze_aglina_fullbody_candidates_v3.py`），源帧 **22–125** 仍是最优：11 个身体关节首尾位置 RMS 由旧数据的 0.253 m 降到 0.104 m，两端都处于下降相位，根高度相近（1.14 / 1.13 m）。周期 103 帧 = 1.7167 秒，104 个采样点含闭合端点。运行时入口仍是源帧 40，相位 18。

## 接缝方法（与粗修版不同）

粗修版在接缝两侧各 18 帧用合成的 Hermite / 球面 Bezier 曲线。本版改为**真实数据交叠淡化**：对接缝附近的循环帧 j∈[−22, 22]，姿态取起点侧源帧 22+j 与终点侧源帧 125+j 的 slerp/lerp，权重用五次 smootherstep 从终点侧 1 过渡到起点侧 0。两侧都是原动作真实运动（源帧 0–44 与 103–147 都存在），所以速度、加速度自然连续，头发等链条保留原有摆动而不是被曲线抹平。源帧 45–102 完全未改。
