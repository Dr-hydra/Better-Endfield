# Better Endfield Next 4.2.2

Windows / Android 软件版本 4.2.2，Android versionCode 40202。
BEM Tools / DSH 保持 1.6.8。
资源包不重发：core 仍为 1.6.3.3 / 1.6.4.4。

本次为安卓端修复与导入体验更新，Windows 端行为不变。

## 自定义模型

- **主世界不显示的模型恢复显示。** 手机场景 LOD1 的材质槽可能比 Windows 少；旧逻辑把“场景少一个槽”当成包错误，整包回退原模型。现在只跳过场景不存在的 keep 覆盖槽，组件其余部分照常替换；女管（基石）的白发规则已恢复。
- **导入时按设备能力选择纹理格式。** 导入会读取包内纹理格式，并探测设备的 BC1/BC3/BC4/BC5/BC7 与 ASTC 支持：
  - 包内格式全部受支持时不做整包重编码。支持 BC7 的设备直接使用 BC7 包，避免无谓的有损转换。
  - 存在不支持的格式时才自动转换：支持 ASTC 时颜色贴图转 ASTC 6×6、线性数据转 ASTC 4×4；不支持 ASTC 时转 RGBA32。
  - 已安装的旧包仍可在管理卡片手动转换；手动转换同样按设备能力选择 ASTC 或 RGBA32。
- **导入报告新增纹理格式统计和探测结果**（`texture_formats`、`gpu_texture`），便于判断某个包为什么转换或没有转换。

## 诊断日志

- **关于页新增「诊断日志」导出。** 一次收集模块状态、框架作用域内每个游戏包的 `betterendfieldnext-*.log` 和 `BetterEndfieldNext` logcat，生成一份报告并通过系统分享面板发出。
  - 游戏侧日志通过单次只读 root 脚本读取；无 root 时仍导出模块状态并注明原因。
  - 在隔离其他包数据目录的 ROM 上通过 `/proc/1/root` 读取。
  - 每份滚动日志取最新 1 MiB，整份报告上限 4 MiB。
