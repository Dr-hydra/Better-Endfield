## 1. 安装

从 [Releases](https://github.com/honxi1/Endfield-Poser/releases) 下载最新的 `EndfieldPoser-v*.zip`
（包里的 `安全安装.bat` 可走安装/卸载向导），
把里面的文件按下面放到游戏目录：

> 🧙 **省事做法**：直接双击包里的 `安全安装.bat`，把游戏根目录拖进窗口按提示走。
> 它会校验游戏目录 → 把原版 `d3dcompiler_47.dll` / `vulkan-1.dll` 备份成 `.backup` → 安装；
> 卸载时还原备份，并且**只删插件文件，不会动你的 `plugin\poses` 姿态预设、日志和已有配置**。
> 想手动装就是下面这张表。

| 包内文件 | 放到 |
|---|---|
| `d3dcompiler_47.dll` | 游戏根目录（**先备份游戏自带的那份**） |
| `vulkan-1.dll` | 游戏根目录（**同样先备份**） |
| `plugin\poser.dll` | 游戏根目录的 `plugin\` |
| `plugin\poser_config.txt` | 游戏根目录的 `plugin\` |

> 📁 **看清楚是 `plugin\`（单数），不是 `plugins\`（复数）**。
> 游戏目录里两个都有：`plugin\` 是插件目录（我们的东西放这里，没有就自己建一个），
> `plugins\` 是游戏自带的 Qt 插件目录（`imageformats/`、`platforms/` 等），放错不会生效。

> ⚠️ **用官方启动器（Hypergryph Launcher）启动游戏**。
> **不要直接双击 `Endfield.exe`**：会跳过官方初始化流程。早期版本还会在 IL2CPP 初始化
> 完成前注入而触发 Unity GC 致命错误（弹 `Threads explicit registering is not previously enabled`），
> 现在插件会等运行时就绪再接入、超时就安静不加载（不再把游戏带崩），但直启仍不推荐。

## 2. 第一次启动：确认插件活着

> 📜 **先点同意**：第一次启动会弹出「用户协议与免责声明」，把条款滚到底后
> 「同意并继续」才会变成可点。**点不到就按住 Alt** 呼出游戏光标再点（游戏平时把鼠标
> 锁起来转视角）。**没同意前插件什么都不做** —— 不装 hook、不读写游戏数据，
| 等待同意协议 | 按面板快捷键（默认 `L`），读完弹窗并选择是否同意 |
> 点「不同意（本次不加载）」不会加载任何功能；之后按面板快捷键可以把这个窗口叫回来，
> 不用重启游戏。

启动游戏后，在游戏目录找两份文件：

- `plugin\poser_log.txt` —— 日志，正常启动应该能看到这几行（顺序即执行顺序）：

  ```
  [POSER] === Endfield Poser v0.3.6 attached ===
  [CFG] gui_toggle_key=...
  [POSER] Resolving IL2CPP...
  [POSER] Starting GUI thread.
| 等待同意协议 | 按面板快捷键（默认 `L`），读完弹窗并选择是否同意 |
  [GUI] attached to IL2CPP domain
  [GUI] ImGui initialized, panel ready
  ── 这时面板上出现协议弹窗：读到末尾 → 点「同意并继续」 ──
  [LEGAL] terms accepted -> installing game hooks
  [OK] PlayerController.SetMainCharacter hooked
  [SMC] ... / [GUI] ... / [WEB] ...
  ```

  **只要卡在 `Resolving IL2CPP...` 没有再往下，就是没走启动器**——关掉重开即可。

- `plugin\poser_log.txt` 里的 `[GUI] ImGui initialized, panel ready` 出现后，按 **L** 就能呼出面板。
  （默认键是 `L` / `P`；想在游戏内打字时不误触发，可以改成带 Ctrl 的组合。）

**改键（推荐用它，别手改文件）**：主面板顶部有个 `快捷键（可改）` 折叠区，
点某一行的 `改键` → 直接按下你想用的键 → 自动生效并写回 `plugin\poser_config.txt`，按 `Esc` 取消。

- 想带修饰键：按住 `Ctrl`（或 `Shift`）再按主键，例如 `Ctrl+Insert`；
- **单键也允许**（Insert/Delete… 甚至 `L` 这种字母）。但绑单字母要注意：
  热键是全局轮询、也不会被吞掉，所以**游戏内文本框/聊天里打字会误触发**——
  绑了单键后主面板会给出提醒，建议按住 `Ctrl` 重设一个组合。
  （插件自己面板里的输入框打字时不会误触发，这条已经做了屏蔽。）
- 默认键是 `L` / `P`（避开其它插件常用的按键）；绑"会打字"的单键（字母/数字）时，
  快捷键区里会提示游戏内打字会误触发。
- 热键只在**前台是游戏窗口**时生效，在浏览器/聊天里打字不会误触发。

面板一共有几个窗口（都有默认位置，**拖标题栏就能移动**，位置会记住）：

| 窗口 | 作用 |
|---|---|
| Endfield Poser（左上） | 主控制：冻结、骨骼显示、窗口开关、快捷键、调试 |
| 骨骼参数（中上） | 选中骨的旋转/位置参数 + **人物位置(Root XYZ)** + IK 控制器面板 |
| 姿态库（左中） | 姿态预设的保存/载入/删除 |
| 形态键（右上） | SMC 表情滑条 |
| 角色（默认关闭） | 场上角色列表，点「编辑」切换要摆的那个角色 |

这些窗口由主面板的 **「窗口」** 组统一开关：默认只开主面板和「骨骼参数」，勾上就出现，
点窗口右上角的 × 也会关（两处是同一个状态）；**勾选状态会记住**（写回 `poser_config.txt`）。
主面板底部还有一个默认收起的 **「调试」** 组（扫描角色、骨骼数 / Animator、快捷键一览）。

还有一个 WebUI：浏览器打开 `http://127.0.0.1:18923`。

## 3. 冻结：把角色定住

**按 P（或点主面板的 `Freeze Character`）。**

冻结做了三件事：

1. 关掉 Animator，角色停在当前帧；
2. 抑制 FinalIK / Grounder 等会写骨骼的组件；
3. 按选项钉住头发、裙子、飘带等从骨（主面板「冻结飘带/裙子/头发」，默认开）。

再按一次 P 解冻，一切恢复。**摆姿必须在冻结状态下做**——没冻结时游戏每帧都会把骨骼覆盖回去。

### 切换角色时会怎样

冻结状态是**按角色记住**的，所以可以逐个角色摆姿：

- 冻结 A → 切到 B：**B 保持默认**（不冻结、正常活动）；
- 摆好 B 并冻结 → 切回 A：**A 恢复你离开时的姿势**（它的 Animator/IK 会被重新压制）；
- 后台已经冻结过的角色不会被游戏重新拉走，会一直保持你摆好的样子；
- 只有**当前角色**能编辑（骨架列表、从骨、形态键都跟着当前角色）；要改别的角色，先切过去。

日志里能看到 `[CHAR] saved frozen state for ...` / `[CHAR] restoring frozen state for ...`，
以及 `[CHAR] '...' has no saved frozen state -> leaving it unfrozen`。

## 4. 摆姿势：点、拖、拉

### 点选骨骼

- 默认只显示 **humanoid 骨**（55 根）——干净，够用；
- 要选手指、头发这类，勾主面板的 **「全量骨骼(微调)」**；
- 3D 视图里关节会画成小圆点，**鼠标靠近会出白色提示圈**，点一下就选中（变黄）；
- 选中骨上会出现**旋转盘**，拖外圈即可旋转；点空白处取消选中。

### 参数面板（精调）

选中骨后，在「骨骼参数」窗口里能：

- **旋转**：一条滑条（可拖）+ 一行输入框（可键入具体角度，单位是度）；
- **位置**：同上，小数位更细；
- **步长 + XYZ ± 按钮**：点一下走一个步长，适合"再转 5 度"这种微调；
- **复位旋转 / 复位位置 / 全部复位**：把该骨恢复到基线（humanoid 骨回到 A-pose，从骨回到冻结瞬间）；
- **锁定**（humanoid 骨）：锁定后快照恢复/镜像等操作会跳过它。

> 输入框要打字：先让光标出来（见 [第 9 节](#9-面板操作与输入模型)），点进输入框直接敲，回车或点到别处即生效。

### 「全部重置」

主面板的 `全部重置` 会把**所有骨（含从骨）恢复到你按 P 冻结那一刻的姿态**——
摆乱了想重来，点它就行，不用解冻重冻结。

## 5. 头发/裙子/飘带（从骨）

这些"从骨"是挂在骨架上的动态链（不是 humanoid 55 根之一）：

1. 勾主面板 **「全量骨骼(微调)」**，头发/裙子/飘带的骨点就会出现，可以直接点选、旋转；
2. 冻结时它们被钉在冻结瞬间的姿态；**你手动改过的那根会以你的改动为准**，不会被每帧回写打回去；
3. 想让某条链回到冻结时刻的样子：选中它 → `复位旋转`。

> 从骨里的 `Nub`/`Twist`/`corrective`/碰撞体/表情骨等内部骨会被自动过滤，不会出现在画面里。

## 6. 调整人物整体位置

冻结后主面板会出现 **人物位置 (Root XYZ)**：

- 滑条拖动、输入框键入具体值，或用 **步长 + XYZ ±** 按钮微调；
- 适合把角色挪到取景中心、或做"离地/下沉"的效果。

## 7. 表情

「形态键」窗口分两段：

- **游戏原生表情 (SMC)**：本作面部由骨骼变形驱动（SkeletalMorphCore），这里列出**口型**与
  **表情**滑条（微笑、生气、眨眼…）。拖动即生效（需在冻结态）。
- **BlendShape**：本作网格上没有 BlendShape 目标，**这一段为空是正常的**。

**默认值、冻结与三个按钮**（v0.3.2 起）：

| 操作 | 行为 |
|---|---|
| 滑条值 | 恒为**相对"中性默认脸"**的权重——中性默认脸在角色被捕获后自动采样，等价于面部的 A-pose，**不是**你冻结那一刻的脸 |
| 冻结 | **保持当前表情**：冻结瞬间插件把此刻的脸反解成滑条值（拟合不出的残差留在内部基准里），因此脸不会跳变 |
| `全部归零` | 权重 + 基准一起复位 → 回到中性默认脸 |
| `读入当前表情` | 把游戏当前的表情权重读进滑条（先复位基准再填），等价于"把脸设成游戏当前的表情" |

日志里能看到两行判定：`neutral baseline captured: ...`（默认脸采样完成）与
`hold current face: sliders fitted (N expr nonzero), residual=...`（冻结时的反解结果）。

**注意（已知限制）**：表情（SMC 权重）不写入姿态预设，也**不能跨角色通用**——
不同角色的骨架与 morph 表不同，套用会得到错位或夸张的脸。表情请在当前角色上调。

## 8. 保存与套用姿态预设

「姿态库」窗口：

| 按钮 | 说明 |
|---|---|
| 保存预设 | 用「命名」里的名字保存；留空则自动编号 `Pose_001` |
| 覆盖保存 | 覆盖列表里选中的那条 |
| 加载 | 套用选中预设到当前角色 |
| 删除 | 删除选中预设 |
| 刷新列表 | 重新扫描目录 |

存储位置：`<游戏目录>\plugin\poses\*.poser.json`（面板底部也会显示当前路径，
可用配置项 `default_pose_dir` 改）。

**「不保存/不套用表情」默认勾选**：姿态只含身体与从骨，跨角色套用时脸不会被弄乱。
想让姿态带上眼睛/下巴（**仅供同角色使用**）就取消勾选。

推荐工作流：冻结 → 摆好姿势 → 命名保存 → 换姿势继续保存 → 需要时从列表里加载。

## 9. 面板操作与输入模型

插件用的是"覆盖层 + 真穿透"模型，规则很简单：

| 状态 | 鼠标/键盘归谁 |
|---|---|
| 没按 Alt（光标被游戏锁住） | **全部归游戏**，正常走位、转镜头 |
| 按住 Alt（或游戏自己放开光标，例如摄影模式） | 指针在面板/关节上时归面板，其余仍然归游戏 |
| 点进输入框 | 键盘临时归面板，可以打字；点到别处立刻还给游戏 |

所以：**要操作面板，先按住 Alt**；松开 Alt 面板依然可见，只是不再吃鼠标。

窗口位置直接拖标题栏移动即可（位置会被记住）；拖旋转盘 / 滑条不会带动窗口。

## 10. 排查：出问题先看这里

**先看 `plugin\poser_log.txt`**，绝大多数问题日志里都有答案。

还是搞不定就把日志和复现步骤发到交流群（QQ 群 **1126684901**，终末地影棚爱好者）或 issue。

| 现象 | 原因 / 处理 |
|---|---|
| 游戏启动异常 | 插件会等待游戏运行时就绪；保存日志与启动方式反馈，确认已完全退出旧进程 |
| 长时间未出现面板 | 查看日志是否提示等待游戏运行时；确认使用最新构建，并等待进入角色场景 |
| 等待同意协议 | 按面板快捷键（默认 `L`），读完弹窗并选择是否同意 |
| 弹窗出现但点不动 | 游戏平时会把鼠标锁起来转视角：**按住 Alt** 呼出光标再点（弹窗里会提示当前状态）。指针落在弹窗之外时点击照旧给游戏 |
| 装了其它注入类 mod 后面板未出现 | 官方包不针对这类环境做兼容（覆盖层走 DComp）；请用官方启动器进入游戏 |
| 面板看不见但游戏正常 | 使用窗口化或无边框全屏；确认没有第三方注入类 mod，并检查 `poser_log.txt` 的覆盖层初始化结果 |
| 面板呼不出来 | 确认按的是配置里的键（默认 `L`）；确认日志有 `panel ready`、`[CFG]` 里打印的键码对得上 |
| 热键"有时有用有时没用" | 多半是和别的插件抢了同一个键：在面板 `快捷键（可改）` 里换一个带 `Ctrl` 的组合 |
| 点不动面板/骨骼 | 没按 Alt；或指针没落在关节 14px 内 |
| 鼠标"消失" | 游戏把系统光标隐藏了，插件会补一个软光标；若仍看不见，按住 Alt 试 |
| 骨骼数为 0（面板显示 `Bones=0`） | 角色还没加载完，或不在有角色的场景；进场景后按「刷新骨骼」 |
| 改完姿势被弹回去 | 没冻结；或该骨被游戏 IK/布料覆盖（冻结会抑制它们） |
| 表情滑条没反应 | 先在冻结态；若仍无反应，看日志里 `[SMC] hold current face: ...` 与 `[SMC] weights sum=...` 两行 |
| 冻结后表情被"洗掉"了 | v0.3.2 起不该出现：冻结会反解并保持当前表情。真出现就看 `[SMC] hold current face: ... residual=` 与 `neutral baseline captured: ...` 两行 |
| 只有部分角色能调表情 | v0.3.2 起按 SMC 实例归属匹配当前角色；若日志频繁 `reject instance ... no bone overlap`，把那几行发出来 |
| 姿态套到别的角色上脸乱了 | 姿态默认不含表情；若旧文件带表情数据，载入时会跳过。已乱的脸请解冻→重新冻结拿干净快照 |

## 11. 速查表

| 操作 | 键 / 位置 |
|---|---|
| 呼出/隐藏面板 | `L`（主面板 `快捷键（可改）` 里一键改键，或 `poser_config.txt` 的 `gui_toggle_key`） |
| 冻结 / 解冻 | `P`（同上，`freeze_key`） |
| 取消选中骨骼（收起旋转盘） | 点 3D 视图的**空白处** |
| 面板交互 | 按住 `Alt`（或游戏自己放开光标时直接点） |
| 移动人物 | 主面板 人物位置（滑条/输入/±） |
| 全部重置（回冻结瞬间） | 主面板 `全部重置` |
| 姿态保存位置 | `<游戏目录>\plugin\poses\` |
| 日志 | `<游戏目录>\plugin\poser_log.txt` |
| WebUI | `http://127.0.0.1:18923` |

配置项（`plugin\poser_config.txt`）：

```
gui_toggle_key=L          # 支持 L / CTRL+L / INSERT / 0x2D
freeze_key=P              # 冻结 / 解冻（可改，写法同上）
click_through=1           # 1=覆盖层常驻并真穿透（推荐）；0=按住 Alt 才显示面板
default_pose_dir=plugin\poses
```


## MMD 表情模式

1. 表情面板**默认就是 MMD 表情**（想用游戏自带滑条就切左边那个「游戏表情」）；点“冻结并编辑”，等待表情准备完成。无需加载 MMD 动作。
2. 展开“眉毛 / 眼睛 / 嘴部 / 其他”，拖动中文表情滑条。可以搜索、叠加多个表情；悬停名称查看原始名称与映射来源。
3. “整体强度”调节所有表情幅度，默认 100%；“归零”“本组归零”“全部归零”分别清除对应权重。
4. 默认优先使用角色专属映射。“缺失时使用固定映射”可补充缺少校准的表情；关闭后未匹配项会显示不可用。
5. 按 `L` 隐藏面板仍保留表情；按 `P` 解冻恢复游戏控制。切回游戏模式会恢复进入 MMD 模式前的表情滑条。切换编辑角色或刷新骨骼会清除 MMD 权重，避免串到其他角色。

校准随安装包提供，位于 `plugin/mmd/character-faces/`。手动安装时须同时复制该目录。缺少资源仍可使用固定映射；修改校准后需重启游戏。MMD 权重暂不保存到姿态文件。

内置 MMD 表情参考自[茶叶味香皂](https://space.bilibili.com/3546783156276148)的模型，不包含模型本体。材质、贴图等特殊效果不可用；替换模型或面部骨架差异较大时可能需要新的校准。

## MMD 动作、音乐与镜头

打开主面板的 **MMD 播放器**，选择 VMD 并完成当前角色校准，再播放。快捷键：`Ctrl+F5` 播放、`Ctrl+F6` 暂停、`Ctrl+F7` 停止恢复、`Ctrl+F8` 回到首帧。按 `L` 隐藏面板后继续播放。

暂停可保存当前身体姿态；播放期间骨骼编辑、姿态载入和手动表情暂不可用。切换角色或刷新骨架会停止动作并恢复原角色。校准、IK、幅度、音乐及镜头调整见 [MMD 播放指南](mmd-player.md)。

## 眼睛朝向

在表情面板选择 **手动方向** 或 **自动看向镜头**，冻结或播放时生效。左右、上下滑条用于调整或微调；**方向归零** 清除偏移。镜头在身后时回到正前方，近距离限制双眼汇聚，避免过度对眼。切回 **跟随游戏 / 动作** 即恢复原眼神。

## 四人同步与倒计时

勾选主面板的 **MMD 多人播放器**，按小队第 1–4 位选择动作，或将当前动作应用到四人。以游戏当前操控角色的起点为共同原点；先用 **四人横排**，再微调各人的站位。点击 **播放全队** 后共用进度，隐藏菜单可继续用快捷键。

在播放器开启可选 **播放倒计时**，人物和镜头会先进入首帧，数字消失后开始动作与音乐。它默认关闭。

多数角色可自动适配，失败时才需要备用 T 姿校准。坡面、台阶可开启 **地形跟随**。镜头支持按身高构图、跟随指定队员，以及保存当前角色与镜头的设置。详细操作与衣物增强限制见 [MMD 播放指南](mmd-player.md)。
