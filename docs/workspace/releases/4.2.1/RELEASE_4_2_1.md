# Better Endfield Next 4.2.1

Windows / Android 软件版本 4.2.1，Android versionCode 40201。
BEM Tools / DSH 保持 1.6.8。
资源包不重发：core 仍为 1.6.3.3 / 1.6.4.4。

本次只调整相机增强页的排版与说明，不改变任何功能行为。

## 相机增强

- **「镜头画面」分组移到页面最上方。** 移除角色近距离虚化以前在页面尽头，要滑到底才能看到；现在打开相机页第一眼就是它。
- **移除了顶部的「自由视角操作」提示框。** 它占掉一整块空间，内容又和下面的分组重复。操作说明现在并入「自由视角」标题下的小字。

## 为什么这样改

进入/退出的热键、移动方式、冻结后的行为，本来就是「自由视角」这一组设置的使用说明。把它们放在这一组标题下面，和下面的开关挨在一起，比单独摆在页面顶部更有用——不需要先读一条提示，再往下找对应的开关在哪。

时间冻结的具体热键没有重复写进说明：下面紧挨着「启用时间冻结功能」开关和时间冻结热键输入框，那里已经写清楚了。
