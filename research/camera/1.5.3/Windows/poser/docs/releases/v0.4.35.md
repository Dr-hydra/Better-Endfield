# Endfield Poser 0.4.35

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.35)

## 主要变化

- 新增首次使用协议提示，可选择同意启用或暂不使用。
- 新增 MMD 镜头播放，支持固定起点和追踪角色。
- 可调整镜头偏移、距离及朝向，适配不同身高。
- 镜头与动作、表情、音乐共用进度，停止后恢复游戏视角。

## 下载与安装

在下载页 **Assets** 中选择 `Endfield-Poser-v0.4.35-win64.zip`。`source.zip` 和 **Source code** 是源码，不含可直接使用的插件。

1. 正常退出游戏，完整解压安装包。
2. 双击 **安全安装.bat**，选择包含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏目录。
3. 选择 **安装或更新**。已有配置、布局、校准和姿态会保留。
4. 按原有方式从鹰角启动器、EFMI 或游戏程序启动，阅读并确认首次使用协议。
5. 进入角色场景后按 **L** 打开面板；需要光标时按住 **Alt**。

卸载时退出游戏，运行同一向导并选择 **卸载**。用户数据和备份保留。
