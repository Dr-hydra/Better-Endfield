# Endfield Poser 0.4.26

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.26)

## 主要变化

- 改善直接启动和 EFMI 启动时的面板兼容性。
- 增加脚底防穿地、坡面修正与裙摆碰撞辅助。
- 播放时保留衣物、头发和尾巴的动态效果。
- **冻结飘带／裙子／头发**改为默认关闭，需要静止时手动开启。

## 下载与安装

在下载页 **Assets** 中选择 `Endfield-Poser-v0.4.26-win64.zip`。`source.zip` 和 **Source code** 是源码，不含可直接使用的插件。

1. 正常退出游戏，完整解压安装包。
2. 双击 **安全安装.bat**，选择包含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏目录。
3. 选择 **安装或更新**。已有配置、布局、校准和姿态会保留。
4. 按原有方式从鹰角启动器、EFMI 或游戏程序启动。
5. 进入角色场景后按 **L** 打开面板；需要光标时按住 **Alt**。

卸载时退出游戏，运行同一向导并选择 **卸载**。用户数据和备份保留。

## 使用提示

本版不支持 MMD 镜头。碰撞辅助不能消除所有穿模，骨骼不足的长裙仍可能穿模；辅助选项可能增加性能开销。
