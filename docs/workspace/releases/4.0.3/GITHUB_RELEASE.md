Better Endfield Next **4.0.3** 与 BEM Tools **1.5.3** 同步更新，适配当前终末地 Windows 1.6.3 / Android 1.6.4。

## BE 4.0.3

- 适配新版启动器检查。普通启动、注入器、快捷方式与已有 Steam 国服启动功能接入新的启动流程，无需操作官方启动器界面；仍需保留官方启动器安装文件，正常请求管理员权限。
- **XInput 保持可选**，只在用户点击安装按钮时部署。使用注入器不需要 XInput，配置 Steam 不会自动安装代理或切换加载方式。
- Steam 启动命令按当前加载模式生成，升级或切换模式后请重新复制到 Steam 启动选项。修复正式混淆包的 Steam 资料导入及缓存读取问题。
- 修复新版持续冲刺挂点，更新战斗统计协议、属性与来源归因，修正 MMD 地面检测的布局验证。
- 增量更新角色、动作、四语短语音和战斗资源；当前动作资料包含 37 个角色及变体、4,719 条动作。
- Android 完成 1.6.4 ARM64 关键挂点与调用合同核查，相机模块初始化通过。现有 Next 用户可覆盖安装，保留设置。

## BEM Tools 1.5.3

- 正式角色库加入**祀**，共 34 个角色资料：新增 15 个配对部件、14 个索引资源身份和 58 个纹理资源身份，现有来源识别流程可直接使用。
- 新增 **5 套 BEM 1.4 显式资源工程**：祀完整世界/详情、祀 cloth_04 世界部件、明河及 02/03 世界形态。独立工具与 BE 内置工具均包含这些资料。
- 新资料入口为 `profiles/endfield-1.6.3/README.md`。独立 ZIP 完整解压后打开 `BetterEndfieldNext.BemTools.exe`；无需安装 Python 或 .NET。

祀目前有 8 个部件符合现有来源转换布局规则，其余 7 个仍明确标为不支持。显式资源工程初始为 `keep`，供作者继续添加替换数据，单独打包不会改变模型。新增资源仅有 Windows 证据，不表示任意源 Mod 已可自动转换，也未新增 Android donor 支持。

## 下载与验证范围

- **BetterEndfieldNext-4.0.3-Setup.exe**：Windows x64 安装包。
- **BetterEndfieldNext-4.0.3-Android-arm64.apk**：Android arm64 安装包。
- **BEM-Tools-1.5.3-win-x64.zip**：独立 BEM 创作者 GUI、CLI 与角色资料。

Windows 已实测新版启动校验，以及凛 BEM 原包严格导入和 10 部件开屏替换；BEM 导入、热切换、回滚和恢复的离线检查通过。Android 本轮缺语言资源，BEM 实际替换仍待手机验证；Steam 计时和覆盖层尚未实测。语音 bank、新角色头像及来源转换的缺项继续按实际情况保留。
