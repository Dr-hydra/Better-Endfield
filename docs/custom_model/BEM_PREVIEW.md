# 已安装 BEM 包预览（PC / Android）

实现日期：2026-10-27。

## 入口与行为

- 在第三方模型页面的每个已安装包中点击“预览”。不要求先启用包，也不依赖游戏启动。
- Windows 每次点击创建独立窗口；允许同包或不同包同时预览，各自维护相机、资源、显隐、纹理与缓存。
- Android 使用独立管理器 Activity，不向游戏进程添加网页或渲染依赖。
- 使用当前已保存的外观、选项与形态参数，原生 BEM 解析器负责求值约束、隐藏选项、条件 draw 和贴图槽。
- 原页面调整配置后，在预览中点击“还原已保存”读取新配置；预览里的资源切换、部件显隐、单独查看、相机和贴图开关不写入安装设置。
- 支持鼠标拖动旋转、滚轮缩放、双指缩放；长部件名称在可滚动侧栏/移动底部区域完整换行展示。

## 依赖与失败隔离

- PC 复用现有 WebView2 SDK，只在用户打开预览时初始化 Runtime。缺失时显示安装入口；不在主程序启动时初始化预览。
- Android 使用系统 WebView；缺失时在预览页报告错误。需设备支持 WebGL2，渲染进程退出也只影响预览页。
- 两端共用 resources/bem-preview 离线资源，不下载 CDN 资源，不附带 Node/Python/DSH，不在用户端启动 HTTP 服务。
- Windows 的虚拟主机映射和 Android 的请求拦截只暴露各自会话目录与固定页面资源，不暴露源包的任意文件路径。

## 显示范围与预算

- 只显示包中当前选择的替换网格；原版 keep 部件没有原始几何，不能补齐。
- 显式资源（如普通模型、技能、武器）可以分别选择。预览不改变整体技能/武器组合规则。
- 固定静态模型查看，不播放游戏骨骼动作/驱动动画，不应用游戏根偏移；光照、法线和材质为简化展示；已解析 draw 绑定内按纹理名称识别颜色图，不复现全部游戏材质通道。
- 支持 EXT_texture_compression_bptc 的 WebView 优先原样上传 BC7 压缩块，使用设备尺寸上限内的原始纹理或已有 mip，不转为 RGBA、不重新压缩；单层 BC7 使用线性采样而不生成不存在的 mip。BC1/BC3/BC4/BC5/BC7 的软件路径使用原生块行抽样或离线程解码；ASTC 使用现有 astcenc 的原生解码路径后交给页面。软件路径按设备上限选取现有 mip，最高 4096 边长，所有软件输出共用 64 MiB RGBA 预算；无设备能力信息的 CLI 保留 1024/32 MiB 保守模式；大图通过原生流式读取压缩块行并抽样到预览分辨率（含无 mip 的 12K BC7 图集），不整张展开为 RGBA；超出安全预算的贴图回退素模。
- 单次原生加载及导出采用 192 MiB 上限，流式 BCn/ASTC/RGBA 纹理源最多 512 MiB，Zstd 窗口最多 64 MiB，额外读写缓冲各最多 1 MiB，并仅保留一个压缩块行与缩小输出；非流式源最多 64 MiB，软件路径所有输出贴图基础层 RGBA 像素合计不超过 64 MiB（保守 CLI 32 MiB）；BC7/ASTC 直传计入 192 MiB 场景导出预算；GPU mip 链另有开销。这是按窗口预算，不限制 PC 打开窗口数量。
- 后台暂停绘制；窗口关闭终止本窗口加载、释放 GL 资源并删除临时数据。每个窗口至多保留新旧两个场景目录，便于刷新时完成旧请求。

## 构建与验证

- PC 复用 tools/BemCompose/BetterEndfieldNext.BemCompose.exe 的 preview 子命令。主程序页面资源为嵌入资源。
- Android 在现有安装器原生库加入 preview_jni，不新建额外 APK 外部依赖。共享页面在 Gradle 资源准备阶段打包。
- 原生回归：native/tests/bem_preview_cli_tests.py；覆盖 BEM 1.0、选项、false 条件、隐藏网格、非法约束、资源选择、形态、ZIP、ASTC、不覆盖已有目录与源包不变。
- 真实 Edge WebGL 已用本机已安装武器包检查贴图模型、显隐、纹理开关、桌面/移动尺寸及并行页面。
- Android 已在连接设备 25102RKBEC 上验证「梨诺-恶魔公主 by hajimicat」：当前选项引用的 7 张贴图均走 GPU ASTC，身体和衣服保留 8192×8192，导出无缺失警告，真机画面已检查。其他机型、全部选项与游戏内画面对照仍需继续验收。


## 预览内编辑与保存

- 预览侧栏直接切换包内选项、旧版外观和形态滑条，按源包条件显示可用控件。临时不可用的值仍被记住。
- 修改先生成预览草稿，只有点击「保存设置」才通过管理器原有事务写入安装设置。保存不修改源 BEM 包，也不自动启用包。
- 「还原已保存」丢弃当前草稿并读取最新安装设置。切换预览资源保留草稿。多个 PC 窗口各自持有草稿，显式保存写入当前窗口的配置。
- 「临时显隐 / 单独查看」默认折叠，仅影响查看，不属于保存项。
- 不合法的选项组合或预览失败会保留草稿与上一次画面，同时禁用保存；可继续调整或还原。保存失败保留未保存状态，可重试。源包被替换或移除后须重新打开预览。
- 保存后的游戏生效时机仍遵循现有热切换设置；不开启热切换时下次启动游戏生效。

- 页面自动上报 BC7、ASTC LDR 扩展和 MAX_TEXTURE_SIZE。设备不支持、尺寸无适用 mip 或 GPU 上传失败时，自动使用较高清的软件抽样路径；诊断中显示源尺寸、实际尺寸和 GPU BC7/GPU ASTC/RGBA 模式。BEM 外层 Zstd 解包与 BC7 像素解码是不同步骤。

- ASTC 支持 4×4、5×5、6×6 压缩块及线性/sRGB 格式。GPU 直传不展开 RGBA、不重编码；设备不支持、尺寸超限或上传失败时按压缩块行解码并降采样，避免一次展开完整 8K 贴图。复用现有 astcenc 库，不增加外部运行时依赖。
