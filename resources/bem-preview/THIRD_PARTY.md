# BEM preview sources
The renderer and shaders are extracted from Better Endfield Next's DSH BEM plugin (AGPL-3.0-only), adapted for local manager hosting. No DSH or Node runtime is included.
bcn.js is @bis-toolkit/bcn 1.0.2, a port of BCnEncoder.NET, GPL-3.0-or-later. Its original header is retained. decode-worker.js comes from the DSH plugin.
ASTC decoding uses the repository's astcenc library (Apache-2.0); original license notices remain in the repository.
