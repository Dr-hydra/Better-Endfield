# Endfield Camera Relink V1.0C

> **署名**：一块铅矾
> **辅助模型**：deepseek V4.1 flash / GPT6 Astra
> **思路致谢**：《原神》↔ Blender 联动插件 —— **插件设计：小二今天吃啥　插件研发：Ex_M**（详见[第八节](#八第三方组件与致谢)）
> （本版发布名 **Endfield Camera Relink V1.0C**；工程目录名仍为 `EndfieldCameraLink`，模块与插件标识不变）

用 **Blender 的相机**实时驱动《明日方舟：终末地》游戏内相机的联动工具。

Blender 里改焦距、光圈、对焦距离、相机位置与朝向 → 游戏画面实时跟随。用于拍片、录素材、做分镜预演。

> ### ⚠ 用途与边界（请先读这一段）
>
> - **用途**：单机 / 游戏"拍照模式"下的**取景与镜头联动**。它只做一件事：把 Blender 相机的
>   位置／朝向／镜头参数同步到游戏相机。
> - **不做**：不修改任何游戏数值与账号数据、不与服务器交互、**不提供联机或作弊用途**、
>   **不提供绕过反作弊的手段**，也不改变其他玩家的体验。
> - **技术性质（如实说明）**：联动是**向游戏进程注入一个 DLL** 实现的（游戏挂起启动阶段注入 +
>   挂钩相机管线）。这属于"第三方程序介入游戏客户端"，**可能违反游戏服务条款，存在账号被处罚的风险**，
>   请自行评估后再用。
> - **免责**：本软件按"现状"提供、不含担保；使用后果由使用者自行承担。
>   完整声明见 [`USAGE_BOUNDARY.md`](USAGE_BOUNDARY.md)。
>
> 许可：[MIT](LICENSE)（第三方组件署名见 [`NOTICE`](NOTICE)）

## 一、它能做什么

| 在 Blender 里改什么 | 游戏里发生什么 | 状态 |
|---|---|---|
| 相机 `焦距`（Focal Length） | 视场角变化（长焦/广角） | ✅ 实时 |
| 景深 `光圈系数`（F-Stop） | 背景虚化强度变化 | ✅ 实时 |
| 景深 `对焦距离`（Focus Distance） | 对焦平面前后移动 | ✅ 实时 |
| 景深 `对焦对象`（Focus Object） | 自动跟焦 | ✅ 实时 |
| 相机 `位置`（Location） | 相机平移（相对基线） | ✅ 实时 |
| 相机 `旋转`（Rotation） | 相机转向 | ✅ 实时 |

配套还提供**官方自由相机**开关（游戏内自由飞行视角），并且实测**自由相机与景深可以共存**——
也就是"边用自由相机走位、边由 Blender 控制光圈"这个拍片工作状态是成立的。

## 三、快速开始（双击一个文件就够）

**全部操作都在包根目录的 `相机控制台.cmd` 里**（安装后**不会**在桌面建任何快捷方式）。
双击它 → 用数字选功能：

| 菜单 | 什么时候做 | 说明 |
|---|---|---|
| **[1] 安装配置** | 只做一次 | 路径探测 + **安装并自动启用** Blender 插件 + 自检 |
| **[2] 启动游戏并注入模块** | 每次先做 | 启动游戏并在挂起阶段注入模块（会弹 UAC，点"是"） |
| **[3] 武装相机** | 每次都要 | **进入游戏世界后**运行：取拍照相机实例 + 开自由相机 + 开启位置跟随 |
| [4] 关闭相机控制 | 收工时 | 关掉位姿写入，相机交还游戏 |
| [5] 查看运行日志 | 排查时 | 显示模块日志最后若干行 |
| [6] 重新对齐位置原点 | 需要时 | 把当前游戏位姿与当前 Blender 位姿重新对齐 |
| [7] 从源码重建模块 | 改代码后 | 需要 MinGW-w64 g++ |
| [8] 相机状态 | 排查时 | 查实例是否就绪 + 最近日志 |
| [9] 只安装 Blender 插件 | 需要时 | 只把插件装进用户插件目录 |

安装程序会把 Blender 插件**连"启用"都做好**（后台启动一次 Blender 执行启用并保存偏好设置），
正常情况下你不需要手动进偏好设置勾选。

> **唯一例外**：安装时如果 Blender 正开着，脚本会跳过自动启用（避免你的 Blender 退出时覆盖掉改动），
> 并明确提示你——此时关掉 Blender 重跑一次即可全自动完成。

最后在 Blender 里点 **开始实时发送** 即可。

> 顺序不能颠倒：**[2] 必须在进游戏之前**，**[3] 必须在进入游戏世界之后**。
> 启动后约 30 秒模块才就绪（需要等 IL2CPP 初始化完成）。

> 想要桌面快捷方式的话，控制台菜单 **[0]** 可以按需建一个（安装时不会自动建）。

### 命令行方式（等价，供脚本调用）

```powershell
# 每个功能都能用 -Action 直接调用，跳过菜单
powershell -ExecutionPolicy Bypass -File install\console.ps1 -Action install
powershell -ExecutionPolicy Bypass -File install\console.ps1 -Action launch
powershell -ExecutionPolicy Bypass -File install\console.ps1 -Action arm
# 可选: stop / status / reset / log / addon / rebuild / shortcut
```

> **重要**：请用上面的入口启动游戏，**不要**直接从启动器点开始。
> 因为模块必须在游戏进程**挂起阶段**完成注入——游戏以管理员权限运行且带 ACE 反作弊，
> 运行中注入会被拒绝（`OpenProcess` 返回 err=5），挂起注入还能抢在反作弊完全武装之前完成。

### 验证是否成功

用 `相机控制台.cmd` → **[5] 查看运行日志**，看到：

```
Ready: 相机链路已挂载 (hook ok, UDP 端口 9601)
成功挂上 Cinemachine.CinemachineBrain.LateUpdate -> pose_mode=3 可用
```

武装后再看到 `marketing=` 与 `snapshot=` 都不是 `0`，就全部就绪了。

## 六、必须知道的三条约束

1. **位置跟随要用"相对基线"模式**（默认已开）。
   Blender 场景坐标与游戏世界坐标毫无关系，直接套绝对坐标会把相机搬到关卡外
   → 画面虚空/发灰。相对模式下 Blender 相机不动时游戏相机就停在原地。
   **位移请控制在几米~几十米量级。**

2. **每次进游戏世界都要先 `arm_lens.ps1`。**
   光圈/对焦依赖游戏拍照相机实例，位姿依赖正确的写入时机，两者都需要这一步。

3. **同一时间只能有一个 Blender 在发送。**
   共享内存通道没有写入方标识，双写会导致参数互相覆盖、画面来回跳。

## 七、安全与合规说明

- **本工具通过进程注入实现**，不做内存读写扫描、不修改游戏文件、不修改存档、不联网传输数据。
- 注入模块采用**挂起时注入**：在游戏进程恢复运行前完成，且**全程不向游戏安装目录写入任何文件**
  （模块日志写在包内 `game_mod\EndfieldCamLink.log`）。这样做是为了不打乱启动器的文件校验。
- 所有对游戏的操作都通过游戏自身的公开接口完成（`CameraManager` / `CameraUtils` /
  `SnapshotCameraController` 等），不触碰反作弊组件。
- 本工具面向**单机二创拍摄**用途。请在遵守《终末地》用户协议与社区二创规范的前提下使用。
  因使用本工具产生的账号风险由使用者自行承担。
- 若你的环境对注入行为敏感，或出现过异常，请**停止使用并重启系统**，不要反复尝试。

## 十、升级到新版（一句话版）

**新版压缩包覆盖旧目录 → 双击 `相机控制台.cmd` 跑一次菜单 [1] 安装配置 → 重启 Blender → 照旧 [2] / [3]。**
不需要卸载旧版，也不会覆盖你自己写的运镜预设（`<包根>\presets` 只补缺失的示例）。

升级前必做两件事：

1. **退出游戏**（否则 `game_mod\EndfieldCamLink.dll` 被进程占用，覆盖不进去，游戏里跑的还是旧模块）；
2. **退出 Blender**（否则内存里还是旧插件，而且安装脚本会跳过自动启用）。

菜单 [1] 本身就是升级脚本：它会重探路径、整棵覆盖 Blender 插件、重写
`package_path.txt`、补齐包内 `presets\`，
并顺手检查旧版残留（旧预设目录 / 正在运行的进程）。

> 从 **1.0.0w** 起，`[1]` 会先跑一遍「旧版残留检查」并打印处理建议。
> 完整方案（含必须补做的 3 件事、两种升级姿势、升级后 60 秒自检、回滚、
> 以及可直接复制发给别人的说明）见 `docs/08_升级与旧版迁移.md`。

## 十一、已知问题与限制（先看这里，能省掉一半折腾）

| 问题 | 现状 | 规避办法 |
|---|---|---|
| **【随角色】模式下释放终结技 / 游戏换相机时，游戏可能崩溃** | **未修**（1.0.0av 系列曾修好，但该系列改动过大，已于 2026-09-18 **整体回退**） | 拍摄时改用**【定镜头】**（实测不崩）；或避免在终结技/换场景的瞬间用随角色 |
| 每次进入游戏世界都要重新"武装相机" | 设计如此（光圈/对焦依赖游戏拍照相机实例） | 控制台菜单 [3] 武装相机 |
| 模块与游戏版本强绑定 | 模块按 Unity 2021.3.34f5 的运行时布局编写 | 游戏本体大版本更新后可能失效（现象：日志停在 `[hook]` 阶段），见 `docs/03` |
| 位置跟随的轴向映射未做逐轴校正 | 旋转已修正到 0.00°；位置以"单轴小幅移动"为准 | 大幅位移分几次做 |
| 隐藏 UI 后仍有个别元素残留 | 位 5 上还有"地图样元素 + 部分光效" | 见 `docs/03` §10 |

> 崩溃的**完整取证**与已回退的那套修法（供后来者重做）→ `docs/03_故障排查.md` §6.4 / §6.5。

## 十二、从 Release 包使用 / 从源码构建

**普通用户（推荐）**：下载 Release 里的 `Endfield_Camera_Relink_*.zip` → 解压到任意非系统盘目录
→ 双击 `相机控制台.cmd` → 菜单 **[1] 安装配置** → 菜单 **[2] 启动游戏并注入** → 进游戏世界 → 菜单 **[3] 武装相机**。

**想自己编译**（本仓库**不含**预编译的 DLL / 注入器，二进制走 Release）：

```powershell
# 需要 MinGW-w64 (g++)；可选 Python 仅部分分析工具使用
powershell -ExecutionPolicy Bypass -File source\build.ps1 -OutDir build_ui
# 产物: build_ui\EndfieldCamLink.dll + build_ui\injector.exe  →  复制到 game_mod\ 即可
```

**校验发行包**：Release 说明里会给出 zip 与 `game_mod\EndfieldCamLink.dll` 的 SHA256；
历史上各版本的哈希也逐条记在 `VERSION.txt` 里，可逐版核对。

| 对外 tag | 内部版本 | 说明 |

| `v1.0.0` | 模块 `1.0.0at` + 插件 `0.3.13`，包版本 `1.0.2`（发布名 **V1.0C**） | 首个公开版：回退到"未修崩溃"的干净模块 + 单一控制台入口 + 安装不建快捷方式 |
