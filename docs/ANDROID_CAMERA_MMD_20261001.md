# Android 相机、MMD 与设置整合（2026-10-01）

开发分支：`dev/android-main-bem-import-20260927`。本轮将 `main@3b285742` 合入安卓分支，保留安卓渲染线程控制、JNI ClassLoader 隔离、Hook 所有权与 BEM 打开方式导入。

## 功能与使用

- 悬浮窗左侧纵向切换 HUD、自由相机、冻结、第一人称与 MMD；内容独立滚动，按屏幕安全区域限制宽高。自由相机速度、FOV 使用滑条。
- 收起保留控制点；“本次关闭”隐藏整个悬浮窗，Activity 恢复或重建不重新显示，游戏进程重启后重新按配置显示。关闭会释放按住的输入，保留已启动功能；进入后台时在 Unity 帧上停止播放、退出相机并恢复冻结。
- 时间冻结独立于自由相机。切换相机模式保留冻结，关闭冻结功能或进入后台才恢复模块捕获的原时间倍率。
- 第一人称共享 PC 的头发名称扩展、多 Renderer 扫描、独立头发隐藏和水平侧看后的平滑转身。默认侧看上限 90°、转身速度 360°/秒，可在安卓相机页调整。
- MMD 作品页通过系统目录选择器导入包含 `set.ini` 的目录。动作、表情、镜头、音乐及多人文件沿用 PC 的作品格式。先发布全部不可变文件，再发布作品索引；游戏启动前复制到自己的私有目录。
- MMD 悬浮窗有作品选择、播放/暂停/停止、时间轴、前后跳转、循环、镜头模式和机位管理。关键帧默认保存到游戏私有 `betterendfield/camera-path.becam`。
- 高级设置提供身体/表情、动作比例、衣物物理、地形贴合选项及 orbit/dollyzoom/crane/truck 运镜、平滑、速度、目标高度、持续时间、关键帧时长和循环。
- 同一角色可以安装多个 BEM 包；启用一个会停用同角色其他包。转换只替换目标 generation，移除不影响其他有效包。组件/外观选项收入展开区并即时保存。
- 设置页取消手动保存。开关、选项立即保存；文本 450ms 防抖并在离页时刷新，无效输入保留上次有效值。模块装载和导入文件需要重启游戏；游戏内控制立即执行。

## 布局与接口回退

原共享 UI 在 `mobile_ui_enabled=false` 且没有恢复值时，会把输入类型默认为 Keyboard。安卓只开启 HUD/UID 也可能走该路径。本轮修复为默认不切换任何布局；只有显式启用 PC 布局才调用 `DeviceInfo.ChangeInputType` 并通知 `UIStyleByState`。Keyboard 枚举通过元数据取值，缺少契约则保留原布局。关闭时恢复进入前的 Touch/Controller 模式，不改账号平台声明。

issue #18 报告某个 realme 样本缺少 `il2cpp_domain_get_assemblies`；用户的小米设备并不是该失败样本。品牌不是已确定根因。本轮将程序集枚举与 image 名称查询设为可选；对应导出缺失时使用已经解析的 `il2cpp_domain_assembly_open` 按名字查询，兼容带/不带 `.dll` 名称。正常导出可用时保留原枚举路径，不猜测地址或扫描隐藏符号。

详见 [issue 与资源来源记录](ANDROID_RESOURCE_SYNC_20261001.md)。手机上的回退测试使用模拟缺失接口，不意味着该手机实际缺少接口。

## 平台适配边界

MMD director、VMD 相机与路径文件读写直接共享 PC 实现；安卓用有界命令队列和 JSON 状态代替 Windows 共享内存与伴随窗口。JNI 只提交控制请求，Unity 对象操作在已经观察到的帧线程执行。

EIEM 原 PC 的 Windows/SEH 和原生对象布局不能直接用于 ARM64。安卓适配复用 EIEM 的解析、采样与 DirectVmd 数学，用托管接口绑定角色、FK/扭转骨、腿部求解、表情和衣物状态。具体能力依赖对应客户端元数据，缺失只禁用该能力并记录日志；不能把编译或离线测试当作实际舞蹈、布料效果验收。Camera 与 Actions 共享同一姿态租约，避免同时写同一骨架。

安卓本地音轨通过 MediaPlayer 实现相同 `BE_LocalMusicApiV1` 时间轴接口；准备、播放、暂停、跳转与状态采集在媒体线程执行。音量范围 0–1。这不是 PC 的 Wwise/OmniMix 排他通道，会叠加游戏 BGM，作品页提示用户关闭游戏背景音乐。媒体代次检查与状态发布串行，旧回调不能覆盖新作品的状态。

地形跟随通过 `ComputeFloorDist` / `FindFloor` 及实际分配并固定的托管 `FindFloorResult` 调用，按字段/方法名称读取命中、可行走面、高度和法线；不使用 PC 的结果缓冲区尺寸或字段偏移。每个角色共享 EIEM 的地形平面、根高度和脚趾求解数学，镜头引用包含地形高度偏移。暂停保持地形状态，跳转重置状态；接口缺失或托管异常只关闭地形，在 MMD 悬浮窗显示原因，普通动作和相机继续。
