# Legacy 对照归档

本目录保存已经结束维护的历史版本源码和参考文件，只用于版本差异分析、Hook
兼容性排查和行为回归对照。

## 使用规则

- 归档内容视为只读，不在原目录内修复、格式化或重新生成文件。
- 需要试验历史代码时，先将对应快照复制到归档目录之外。
- 当前产品构建、打包和资源更新不得引用 `legacy/` 下的文件。
- 每个快照必须记录产品版本、来源提交和资源兼容边界；未知信息明确标为未知，
  不根据日期或文件名推断。
- 不归档游戏 PCK、BNK、WEM、VFS 原始包、客户端二进制、日志或构建产物。
