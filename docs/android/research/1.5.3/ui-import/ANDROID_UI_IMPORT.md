## MMD 导入

- 支持 ZIP（UTF-8/常见 GBK 文件名）、7z、目录和分别选文件。RAR 或加密包显示不支持，没有假装识别成功。
- 读取 VMD 实际骨骼、表情和相机节进行分类，支持一份 VMD 包含多种内容。已有 `set.ini` 优先读取并重写文件引用；没有配置文件时生成可编辑候选作品。
- 导入页可选作品、改名，分别选择/清空动作、表情、镜头、音乐，展开第二至第四人的动作与表情。多个候选不能确定时保留选择，用户确认后才安装。
- 嵌套目录资源整理为作品内单层文件并生成 `set.ini`，保持原 UUID generation 和 `files[{remote,name,bytes}]` 索引，兼容已有游戏端读取。
- 实际限制：单 VMD 64 MiB、音频 512 MiB、资料/作品 1 GiB、文件数 4096、目录深度 16。拒绝绝对路径、路径穿越、重复路径、符号链接、异常长度；ZIP 校验 CRC，7z 解码内存有上限。
- 缓存准备、复制、解压在后台进行，Activity 重建可恢复已准备资料；取消等待 worker 停止后才清理缓存，避免删除正在安装的来源。全部文件发布成功后才写作品索引，失败保留既有作品。

动作和镜头引用同一 VMD 时，共享 director 现在按“动作内运镜”比例适配，避免自动识别后因两个槽引用同文件而错误使用独立镜头比例。
