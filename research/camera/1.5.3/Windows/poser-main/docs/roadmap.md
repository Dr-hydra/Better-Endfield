# Endfield Poser 路线图

> 面向使用者的功能概览与后续计划。安装与使用见 [README](../README.md) 与
> [tutorial.md](tutorial.md)。

## 已完成

- **MMD 播放**：动作、表情、眼神、镜头及可选音乐同步，支持角色校准和动作适配。
- **眼睛朝向**：手动调节或自动看向镜头。

- **角色冻结**：关闭角色动画并抑制其它写骨骼的系统，每帧维持当前姿态；从骨（飘带 / 裙子 /
  头发）可选跟随冻结，或保持实时演算。
- **摆姿编辑**：3D 视图点选骨骼 + 旋转盘拖动；旋转 / 位置支持滑条、数值输入、± 步进与复位。
- **人物位置**：Root XYZ 滑条、精确输入，以及可调步长的 ± 步进。
- **从骨控制**：头发、裙子、飘带等从骨可单独编辑，编辑结果会同步进冻结基线。
- **姿态预设**：命名保存 / 覆盖 / 载入 / 删除（含从骨数据）；保存位置可配置。
- **形态键与表情**：面部 BlendShape 面板 + 游戏原生 SMC 表情；滑条值以"中性默认脸"为基准，
  冻结时保持当前表情。
- **多角色**：冻结状态按角色记忆；切回冻过的角色会恢复离开时的姿势。
- **输入与光标**：面板与游戏各自持有输入，按 `Alt` 取回光标；覆盖层默认真穿透。
- **WebUI**：插件启动后监听 `http://127.0.0.1:18923`，可在浏览器中作辅助界面。
- **兼容**：支持 DX11 与 Vulkan；默认构建使用官方启动器。

## 计划中

1. **动作库 / 共享姿态**：姿态文件带元数据（作者、角色、标签），支持从链接导入。
2. **多角色列表**：已支持独立编辑，后续完善状态提示。
3. **控制器**（实验性 / 进行中，未发布）：IK 控制器（代码已在仓库，实测骨骼不跟随目标点，
   默认整体关闭）。
4. **骨骼参数面板**：在点选拖动之外，提供数值化的骨骼参数编辑。
5. **更新检查**：启动后检查新版本并给出提示（不自动替换）。
6. **Blender 桥接（已雪藏）**：曾做到在 Blender 内摆姿并实时同步回游戏，暂时停更，
   方案与代码保留。

## 已评估、暂不做

- 骨骼镜像、撤销 / 重做、骨骼层级树：做过但实测问题较多，暂不提供。
- 多角色同步播放、MMD 物理和游戏模型外观导入暂不包含。

## 已知限制

- 表情数据不随姿态文件跨角色通用：不同角色的面部骨骼并不通用，套用会错位，需在新角色上重调。
- 表情滑条只覆盖游戏自带的固定表情集合，其它形态由内部基准保持。
- 相机参数不随姿态文件保存。
- 冻结后骨架有极轻微颤抖（不影响摆姿与保存）。
- 第三方渲染注入环境不在支持范围内，也不在近期的计划里。
