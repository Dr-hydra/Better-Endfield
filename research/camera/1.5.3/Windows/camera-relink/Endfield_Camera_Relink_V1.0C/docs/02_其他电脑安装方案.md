# 在其他电脑上安装部署

> 面向"把这个包拿到另一台电脑上用"的场景。按本文照做即可，不需要写代码。

---

## 一、分发方式

有两种，任选：

### 方式 1 · 目录拷贝（推荐）

直接把整个 `EndfieldCameraLink` 文件夹拷过去（U 盘 / 网盘 / 局域网共享均可）。
包内组件已编译好且**静态链接**（不依赖 VC++ 运行库、不依赖 MinGW），拷过去就能用。

### 方式 2 · 压缩包

```powershell
Compress-Archive -Path D:\EndfieldCameraLink -DestinationPath D:\EndfieldCameraLink.zip -Force
```

目标机器解压到**任意目录**（路径含空格、中文都可以，但建议避开系统盘的只读区域）。

> 建议解压到非系统盘，例如 `D:\EndfieldCameraLink`。
> **不要**放进游戏安装目录——那会打乱启动器的文件校验。

## 二、目标机器要求

| 项目 | 要求 | 怎么确认 |
|---|---|---|
| 操作系统 | Windows 10 / 11 **64 位** | `设置 > 系统 > 关于` 看"系统类型" |
| 游戏 | 《明日方舟：终末地》PC 版，已通过启动器完整下载过 | 启动器能正常进游戏即可 |
| Blender | 3.6 或更高（5.x 已实测通过） | Blender 里 `帮助 > 关于 Blender` |
| 权限 | 能通过 UAC 提权（管理员账号） | 游戏本身就需要管理员权限，能玩就能用 |
| 磁盘 | 约 30 MB（含源码；只要成品约 4 MB） | — |
| 网络 | **不需要**（全程本地通信，只走 127.0.0.1 与命名共享内存） | — |

**不需要**：Python、.NET SDK、MinGW、Visual Studio、任何运行库安装。

## 三、部署步骤

### 第 1 步 · 解压/拷贝到位

确认目录结构里有这些关键文件：

```
EndfieldCameraLink\
├── game_mod\EndfieldCamLink.dll      ← 必须有
├── game_mod\injector.exe             ← 必须有
├── tools\launch_game.ps1             ← 必须有
├── tools\arm_lens.ps1                ← 必须有
├── blender_addon\endfield_camera_bridge\__init__.py
└── install\install_all.ps1
```

### 第 2 步 · 运行安装程序

**双击包根目录的 `相机控制台.cmd`**，在菜单里选 **[1] 安装配置**（或命令行
`powershell -ExecutionPolicy Bypass -File install\console.ps1 -Action install`）。

它会自动完成三件事：探测游戏与 Blender 路径 → 安装并启用插件 → 完整性自检。
**安装时不会创建桌面快捷方式**：所有操作都在这个控制台菜单里（想要桌面图标可用菜单 [0] 按需建一个）。

> **关于执行策略**：`.cmd` 启动器内部已经带了 `-ExecutionPolicy Bypass`，
> 所以双击即可，不会因脚本策略被拦。
> 如果你手工在 PowerShell 里跑 `.ps1` 遇到策略限制，也用 `-ExecutionPolicy Bypass` 参数，
> 它只临时放行本次执行、不修改系统设置。

### 第 3 步 · 检查 `paths.ini`

安装脚本会在包根目录生成 `paths.ini`。打开确认三行路径都对（含空格不用加引号）：

```ini
game_exe=D:\Hypergryph Launcher\games\Endfield Game\Endfield.exe
launcher_exe=D:\Hypergryph Launcher\Launcher.exe
blender_exe=C:\Program Files\Blender Foundation\Blender 5.2\blender.exe
```

**探测失败的常见原因**：游戏装在非常规位置（如自定义文件夹、外接硬盘）。
此时手工把 `game_exe` 改成实际路径即可。找 `Endfield.exe` 的方法：
启动器里点"打开游戏目录"，或在资源管理器里搜 `Endfield.exe`。

### 第 4 步 · 确认 Blender 插件已启用（通常无需操作）

上一步的安装程序**已经自动装好并启用**了插件：

1. 复制插件文件到 `%APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\`
2. 后台启动一次 Blender 执行 `addon_utils.enable(default_set=True)` 并保存偏好设置

安装输出里看到下面这行就是全自动完成了：

```
[OK] 插件已启用, 偏好设置已保存 —— 无需再手工勾选。
```

**需要手工介入的两种情况**：

| 情况 | 安装时的提示 | 处理 |
|---|---|---|
| 安装时 Blender 正开着 | `检测到 Blender 正在运行 —— 跳过自动启用` | 关掉 Blender 重跑控制台菜单 [1]；或手工勾选 |
| 找不到 blender.exe（未装/装在非常规位置） | `未找到 blender.exe, 无法自动启用` | 手工勾选，或在 `paths.ini` 里填 `blender_exe=` 后重跑 |

手工勾选：`编辑 > 偏好设置 > 插件` → 搜索 `Endfield` → 勾选 **Endfield Camera Bridge**。

**如果搜不到插件**，用 ZIP 方式：`偏好设置 > 插件 > 从磁盘安装...` → 选择
`blender_addon\endfield_camera_bridge.zip` → 勾选启用。

### 第 5 步 · 首次试跑

装好后**打开包根目录的 `相机控制台.cmd`，按菜单序号操作**：

```
[1] 安装配置                    ← 已经做过
[2] 启动游戏并注入模块          ← 现在做这个（会弹 UAC，点"是"）
[3] 武装相机                    ← 进入游戏世界后做这个
```

验证：

```powershell
# 1) 等约 30 秒，确认注入成功（控制台菜单 [5] 查看运行日志 也可以）
notepad <包目录>\game_mod\EndfieldCamLink.log
#    看到 "Ready: 相机链路已挂载" 即成功

# 2) 进入游戏世界后武装，然后确认实例非 0
#    控制台菜单 [3] 武装相机 → 再看菜单 [5] 查看运行日志
#    看到 marketing= 与 snapshot= 都不是 0 即就绪

# 3) Blender 里点"开始实时发送"，然后改焦距试试
```

> 包根目录只有 `相机控制台.cmd` 一个启动器，全部功能（含关闭相机控制、对齐原点、
> 重建模块、只装插件）都在它的菜单里。

## 四、权限、杀毒软件与反作弊

### UAC / 管理员权限

游戏自身的清单要求管理员权限。因此：

- `injector.exe` 必须**以管理员权限**运行（`launch_game.ps1` 会自动请求提权）
- 如果你从**非管理员**的 PowerShell 手工运行注入器，会得到 `CreateProcess 失败 err=740`
- 运行中注入（attach 模式）在非管理员下会得到 `OpenProcess 失败 (err=5)`

### 杀毒软件 / Windows Defender

注入器与注入模块可能被启发式规则误报（**注入行为本身**是触发点，不是恶意代码）。
如果被拦截：

| 软件 | 处理 |
|---|---|
| Windows Defender | `Windows 安全中心 > 病毒和威胁防护 > 排除项 > 添加排除项 > 文件夹` → 选包目录 |
| 第三方杀软 | 在实时防护里把包目录加白名单 |

**不要**为了运行而整体关闭杀毒软件。

### ACE 反作弊

游戏带 ACE（AntiCheatExpert）。本工具的行为边界：

- ✅ 只在**进程挂起阶段**注入，抢在反作弊完全武装之前完成
- ✅ **不向游戏安装目录写任何文件**（模块日志写在包内）
- ✅ 不扫描/修改游戏内存，不修改存档，不联网
- ✅ 所有操作走游戏自身的公开接口（`CameraManager` / `CameraUtils` 等）

仍请注意：

- 部分机器上可能存在**启动期偶发失败**（游戏在 60 秒内以 `0xC0000005` 退出）。
  这是"模块线程与 IL2CPP 初始化竞争"的已知问题，模块已用保守等待规避；
  若仍遇到，**重试一次**即可。
- 若你的账号对反作弊极为敏感，请自行评估风险后使用。

## 五、版本差异怎么处理

### 游戏更新了

模块**不做硬编码地址**，全部在运行时按"程序集 + 命名空间 + 类名 + 方法名 + 参数个数"解析，
因此小版本更新通常无需任何处理。

判断方法：启动后看 `game_mod\EndfieldCamLink.log`：

```
[gamesys] OK  CameraUtils.get_cameraManager
[gamesys] OK  CameraManager.SetOverrideFOVForCurrCamera
[gamesys] OK  SnapshotCameraController.SetAperture
```

如果出现大量 `MISS`，说明接口改名或被剥离。两条路：

1. **先查符号**（不用重建）：
   ```powershell
   tools\send_cmd.ps1 -Id 30                    # 打印所有关键方法签名
   tools\send_cmd2.ps1 -Id 26 -A0 2 -A1 0       # 枚举 CameraManager 全部成员
   tools\send_cmd2.ps1 -Id 26 -A0 1 -A1 0       # 枚举 SnapshotCameraController 全部成员
   ```
   把结果对照 `docs\reference\CAMERA_SYMBOLS.md`，看新名字是什么。
2. 改 `source\src\gamesys.cpp` 里的名字，然后重建（见下一节）。

### Blender 版本不同

插件用 `bl_info` 声明最低 3.6，向上兼容。已在 5.2.1 LTS 实测。
安装脚本会自动给检测到的所有 Blender 版本目录各装一份。

### 换了 32 位系统

不支持。IL2CPP 的 `MethodInfo` 布局、数组数据偏移等 ABI 假设都基于 x64。

## 六、从源码重建（仅在需要时）

什么时候需要：游戏更新导致接口失效、想改功能、想换编译器。

### 1) 安装 MinGW-w64

```powershell
winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT
```

安装后开个新窗口验证：`g++ --version`。
（如果没有 winget，也可以手工下载 WinLibs / MSYS2 的 MinGW-w64，确保 `g++` 在 PATH 里。）

### 2) 构建

```powershell
cd <包目录>\EndfieldCameraLink
powershell -ExecutionPolicy Bypass -File source\build.ps1
```

产物直接输出到 `game_mod\`。也可以用 `-Gpp` 指定编译器：

```powershell
powershell -ExecutionPolicy Bypass -File source\build.ps1 -Gpp "C:\msys64\mingw64\bin\g++.exe"
```

### 3) 重建后直接启动

```powershell
powershell -ExecutionPolicy Bypass -File tools\rebuild_and_launch.ps1
```

它会先结束残留游戏进程（释放 DLL 占用）→ 构建 → 启动注入。

> `source\build.ps1` 只是把 `g++` 命令行串起来，没有隐藏步骤，可以直接读。
> 编译参数：`-O2 -std=c++17 -shared -static`（静态链接 libgcc/libstdc++，所以拷到别的机器不需要运行库）。

## 七、部署验证清单

照这个清单逐项打勾，能覆盖 99% 的问题：

- [ ] `game_mod\EndfieldCamLink.dll`、`injector.exe` 存在
- [ ] `paths.ini` 里 `game_exe` 指向真实存在的 `Endfield.exe`
- [ ] 包根目录有 `相机控制台.cmd`（**安装不会建桌面快捷方式**；需要的话用控制台菜单 [0]）
- [ ] Blender 偏好设置里能看到并**已勾选** **Endfield Camera Bridge**（安装程序应已自动启用）
- [ ] 控制台菜单 [2] 启动游戏并注入，UAC 被接受，游戏正常启动到标题画面
- [ ] `game_mod\EndfieldCamLink.log` 出现 `Ready: 相机链路已挂载`
- [ ] 同日志出现 `成功挂上 Cinemachine.CinemachineBrain.LateUpdate -> pose_mode=3 可用`
- [ ] 进入游戏世界后用控制台菜单 [3] 武装相机，日志里 `marketing=` 与 `snapshot=` 都非 `0`
- [ ] Blender 面板 `状态：正在发送`
- [ ] 改 Blender 相机的 `焦距` → 游戏画面视场角变化
- [ ] 勾 `Use Depth of Field` 并把 F-Stop 设 1.4 → 游戏画面背景虚化
- [ ] 移 Blender 相机位置（小幅） → 游戏相机跟着动

> 用 `相机控制台.cmd` 的 **[8] 查看相机状态** 可以一次性看到实例是否就绪 + 日志尾部，
> 比手工翻文件快。

## 八、卸载

1. 关闭游戏与 Blender
2. Blender `编辑 > 偏好设置 > 插件` → 取消勾选 **Endfield Camera Bridge**
   （可再点"移除"彻底删掉插件文件）
3. 删除整个 `EndfieldCameraLink` 文件夹
4. 如果 `install_blender_addon.ps1` 装过插件，可手工删
   `%APPDATA%\Blender Foundation\Blender\<版本>\scripts\addons\endfield_camera_bridge\`

模块不写注册表、不装服务、不写系统目录，删文件夹即彻底清除。

## 九、常见失败与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| `CreateProcess 失败 err=740` | 没以管理员运行 | 用 `launch_game.ps1`（会自动提权） |
| `OpenProcess 失败 (err=5)` | 游戏已运行且权限更高 | 改用 `launch_game.ps1` 的挂起注入；或先退出游戏 |
| 游戏 60 秒内退出，退出码 `0xC0000005` | 启动期与 IL2CPP 初始化竞争的偶发问题 | **重试一次**；仍失败看 `03_故障排查.md` |
| 游戏卡在启动前握手（无窗口、Player.log 空） | ACE 未初始化 | 加 `-StartLauncher` 参数重跑 |
| 日志里大量 `MISS` | 游戏更新改了接口名 | 用指令 30/26 查新名字后重建 |
| Defender 报毒 | 注入行为被启发式误报 | 把包目录加排除项 |
| Blender 里搜不到插件 | 插件目录版本号不对 | 用 ZIP 方式"从磁盘安装" |
| 游戏目录里出现多余文件 | 手工放错位置了 | **务必不要**往游戏目录放文件；删掉它们 |

更细的现象排查见 `03_故障排查.md`。
