# Endfield Poser 0.4.73

Windows x64 预发布版。[打开下载页](https://github.com/OedoSoldier/Endfield-Poser/releases/tag/v0.4.73)

## 本次更新

- **自动适配**：单人和多人播放时自动读取角色骨架并按腿长适配动作比例；手动 T 姿校准保留为备用。
- **地形跟随**：新增坡面、台阶的脚部与高度调整，支持小队逐人处理和镜头高度补偿。
- **眼神控制**：支持 MMD 播放时锁定摄像机并调整强度；按角色参考校正朝向，增加上下左右及斜向限位，个人调整自动保存。
- **面板整理**：播放控制固定在顶部，其余按动作、镜头与音乐、表情、高级分组；合并重复入口。
- **移除大小控制**：取消试用版的虹膜／瞳孔大小控制及对应 MMD 映射，保留眼睛朝向和摄像机跟随。

已通过构建、42 组自动化测试和 3 项眼神参考测试。自动适配、地形跟随及新版眼神控制尚待完整游戏内验收，本次按预发布提供。

## 安装与更新

在 **Assets** 下载 `Endfield-Poser-v0.4.73-win64.zip`。`source.zip` 和 **Source code** 为源码，不能直接安装。

1. 完全退出游戏，将安装包完整解压到游戏目录之外的文件夹。
2. 双击**新版包内的安全安装.bat**，选择直接包含 `Endfield.exe` 和 `GameAssembly.dll` 的目录，再选 **安装或更新**。
3. 启动游戏，确认使用协议。进入场景后按 **L** 打开面板，需要光标时按住 **Alt**。

无需先卸载；向导自动备份并保留配置、姿态和自定义校准，自动安装 37 份内置表情校准。向导使用包内文件，不会自动下载更新。

## 新功能用法

**自动适配**：打开 VMD 后直接播放；多人在独立播放器分配动作后点击 **播放全队**。若提示自动适配失败，再使用 **高级 → 角色校准 → 备用手动 T 姿**。

**地形跟随**：单人在 **动作** 页开启，多人在 **站位与适配** 页开启 **全队地形跟随**，按需调整贴地强度。默认关闭；它用于脚底贴地，不能消除衣服穿身体。

**眼神锁定**：在独立的 **表情 → 眼睛朝向** 勾选 **MMD 播放时锁定摄像机**。展开 **校正与限位（当前角色）** 微调偏差和转动范围，支持播放中调整。参考不足时使用通用限位，眯眼或替换皮肤后可手动收紧。

**默认快捷键**：L 显示／隐藏面板，P 冻结／解冻；**Ctrl+F5 播放、Ctrl+F6 暂停、Ctrl+F7 停止、Ctrl+F8 重置动作**。隐藏面板后仍可使用，已有自定义按键会保留。
